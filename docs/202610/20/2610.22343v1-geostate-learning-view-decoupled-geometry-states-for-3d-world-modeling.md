## 摘要
近期的3D世界模型越来越多地使用几何基础模型（GFM）的特征作为可预测的世界状态，并受益于其丰富的几何先验。然而，这些特征对视角的依赖性将场景动态与相机引起的变化纠缠在一起，使得由此得到的状态演化更难预测。我们提出 GeoState，一种用于预测式3D世界建模的视角解耦几何表示，它将场景状态演化与依赖相机的观测分离。具体而言，场景分词器将多视角GFM特征聚合为视角解耦的场景状态，几何解码器使用相机射线对其进行查询。随后，自回归世界模型预测未来场景状态，而相机运动则单独建模。因此，预测状态既可以在预测相机下解码，也可以在外部指定相机下解码，同时在整个推演过程中保持单一的由上下文导出的尺度，而无需逐帧尺度对齐。实验表明，GeoState 在 Waymo 上优于先前的3D世界模型，支持几何一致的跨视角查询，并能零样本泛化到 KITTI 和 nuScenes。项目页面：https://hongchang-liu.github.io/GeoState-project-page/

## Abstract
Recent 3D world models increasingly use features from geometry foundation models (GFMs) as predictive world states, benefiting from their rich geometric priors. However, the view dependence of these features entangles scene dynamics with camera-induced variation, making the resulting state evolution harder to predict. We propose GeoState, a view-decoupled geometry representation for predictive 3D world modeling that separates scene-state evolution from camera-dependent observation. Specifically, a scene tokenizer aggregates multi-view GFM features into a view-decoupled scene state, which a geometry decoder queries using camera rays. An autoregressive world model then predicts future scene states, while camera motion is modeled separately. The predicted states can therefore be decoded under either predicted or externally specified cameras, while retaining a single context-derived scale throughout the rollout without per-frame scale alignment. Experiments show that GeoState outperforms prior 3D world models on Waymo, supports geometrically consistent cross-view querying, and generalizes zero-shot to KITTI and nuScenes. # GeoState 论文详细总结

## 1. 核心问题与研究动机

- **背景**：3D 世界模型旨在几何 grounded 的状态空间中表示并预测未来环境，相比像素空间预测可减少表示冗余并提升几何一致性。近期工作开始直接以几何基础模型（GFM，如 VGGT-Ω）的预训练特征作为“世界状态”，因其具备强几何先验与跨场景泛化能力。
- **核心问题**：GFM 特征本质上是**围绕观测视角构建**的，具有强烈的视角依赖性。当相机移动时，即使物理场景完全静止，特征空间也会发生显著变化。若直接将这些特征作为预测状态，时间模型就必须同时预测“真实场景演化”和“相机引起的表征变化”，而两者来源根本不同，导致潜在动力学更复杂、长时预测更困难。
- **关键论点**：一个良好的几何感知表示，未必是合适的世界动力学状态表示。状态应描述“世界是什么”，而相机只应决定“世界如何被观测”。
- **与 FR3D 的区别**：FR3D 虽分离了 ego-motion 与场景预测，但其预测状态仍继承底层重建表示的视角依赖结构；GeoState 主张将这种解耦**内建到表示本身**。

## 2. 方法论

### 2.1 核心思想
从冻结 GFM（VGGT-Ω）的多视角特征中学习一个**固定长度、视角解耦的场景状态（GeoState）**，查询视角仅在解码阶段引入；世界模型直接在该状态空间中预测未来场景演化，相机运动单独建模。

### 2.2 关键技术流程

- **GFM 特征提取**：冻结 VGGT-Ω 联合处理多时刻图像以建立共享坐标锚点（首帧输入视图固定），但场景 tokenizer 仅使用当前时刻同步观测对应的输出，包括 4 个中间层 patch 特征、点图、置信度与估计相机。
- **几何条件化 GFM token**：对每个 patch，将多层特征投影融合为 512 维特征，并与显式几何编码（3D 位置、源相机位姿、Plücker 射线，均经中位数归一化）通过 MLP 融合，得到几何条件化 token。
- **场景状态聚合**：将所有视角的 token 拼接为变长 memory，用 Perceiver 风格 Tokenizer（512 个可学习 query，宽度 512）聚合为固定大小场景状态 `S_t ∈ R^{512×512}`，与视角数量无关。
- **查询条件几何解码器**：给定查询相机（内参+外参），构造 Plücker 射线场，Fourier 编码并 patchify 为 query token；先对场景状态做 scene-only self-attention，再与射线 token 拼接，经 16 层联合 Transformer 与 DPT Feature Adapter，送入**冻结的 VGGT-Ω DPT head** 输出归一化深度，最后用上下文导出的尺度转回米制。
- **世界模型**：采用残差更新 `Ŝ_{t+1} = S_t + F_θ(S_{t-3:t})`，基于 FR3D 的 masked factorized Transformer（12 层，宽度 1152），残差头零初始化使模型初始等价于 Copy-Last；自回归使用滑动四状态上下文。
- **训练目标**：
  - 几何状态学习：`L_rep = L_logD + 0.1·L_grad`，GFM 与 DPT head 冻结。
  - 世界模型两阶段：先单步 4→1 初始化（状态匹配 SmoothL1+余弦 + 解码深度监督），再 7 步自回归 rollout（仅解码深度监督，不做状态匹配）。
- **尺度一致性**：用观测锚点帧的 VGGT-Ω/LiDAR 匹配估计尺度因子，整个 rollout 保持单一 context-derived 尺度，**无需逐帧尺度对齐**。

## 6. 主要结论与发现

- **长时深度预测**：在 Waymo 上，使用预测相机时 GeoState 在所有 horizon 的 AbsRel 与 δ1 均优于 DINO-Foresight、VGGT-World、FR3D；相对 VGGT-World 在 2.0s 时 AbsRel 降低 40.4%，且优势随 horizon 增大，并可持续到训练未见的 1.4s 以外。
- **相机重查询 vs 状态演化**：用未来相机重查询最后观测状态（Copy-Last Pred.）已显著优于重复最后深度图，说明视角变化可通过查询固定状态解释；而 GeoState 预测状态在每个 horizon 均优于相机匹配的 Copy-Last，说明世界模型确实学到了超出相机运动的场景演化。
- **跨查询几何一致性**：预测状态与观测编码状态在三档相机扰动下高度一致，说明仅用深度监督也能学到支持未见视角一致查询的几何结构。
- **零样本泛化**：在 KITTI 与 nuScenes 上无需目标域适配即优于所有对比方法，且预测状态仍优于相机匹配 Copy-Last，说明场景动力学也具备跨域迁移性。
- **表示消融**：GeoState 与普通特征压缩器重建质量相当，但 GeoState 的预测误差显著更低，证明视角解耦使状态空间更可预测。
- **状态监督消融**：单步初始化阶段的状态匹配有益；但在 rollout 阶段持续做潜在状态匹配反而损害长时性能，作者归因于 GFM 特征包含与几何无关的上下文相关变化（附录诊断显示深层特征在上下文变化下相对 L2 差异可达 33.55%，而校准后 DPT 深度差异仅 3.82%）。

## 7. 优点

- **表示层面的解耦**：不是仅在建模层面分离 ego-motion，而是把视角从状态中彻底移除，查询视角只在解码时注入，概念清晰且与“世界是什么/如何观测”的哲学一致。
- **固定长度、视角无关的状态**：与视角数量解耦，支持同一状态被任意相机重复查询而无需重编码。
- **免逐帧尺度对齐**：整个 rollout 保持单一 context-derived 尺度，更符合实际部署需求，也避免了基线中逐帧对齐带来的“信息泄漏”式便利。
- **复用冻结 GFM head**：解码器输出对接冻结 VGGT-Ω DPT head，既约束特征几何兼容性，又避免重新学习稠密几何预测。
- **实验归因设计细致**：表示消融控制重建质量、FRONT-only 控制视角数量、Copy-Last 分解相机与场景贡献、运动分层验证动态建模能力，因果链条较完整。
- **零样本跨数据集验证**：在 KITTI 与 nuScenes 上均有稳定提升，增强结论的泛化说服力。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，难以评估方法的实际训练成本与可复现性门槛。
- **任务覆盖较窄**：评估以深度预测和跨查询重投影一致性为主，未直接评估点云、occupancy、语义或下游规划任务；深度是几何的间接体现，结论向完整 3D 世界建模推广仍需更多证据。
- **场景域偏驾驶**：主要在 Waymo/KITTI/nuScenes 等驾驶数据上验证，虽预训练含通用多视角数据，但对室内、具身交互等场景的适用性未知。
- **依赖 GFM 的上下文敏感性**：附录显示 VGGT-Ω 深层特征受联合输入上下文影响显著（相对 L2 达 33.55%），这会影响以观测特征构造的目标状态质量；作者用“单步状态匹配 + rollout 仅深度监督”缓解，但该问题未被根本解决。
- **依赖 LiDAR 做尺度校准**：推理时需要锚点帧 LiDAR 匹配来估计米制尺度，纯视觉部署场景下该假设可能不成立。
- **相机预测误差传播**：预测相机模式下，相机预测器的误差会直接影响解码深度的评估；虽然作者单独报告了相机预测精度，但端到端误差耦合分析有限。
- **比较公平性存在细节差异**：输入分辨率预处理、FR3D 结果引用而非重训、主实验三视角 vs 基线单视角等，均可能影响跨方法比较的严格公平性。
- **静态子集适配的潜在偏差**：tokenizer/decoder 在 Waymo 静态子集上适配，虽然后续在动态窗口上评估有效，但适配数据选择与动态场景分布之间的匹配程度未充分讨论。
