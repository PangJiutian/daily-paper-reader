## 摘要
近期视频世界模型的进展已能构建逼真的交互式环境，但长时程生成对视觉记忆提出了根本性要求：随着模型持续生成，先前观察到的世界必须保持一致。现有自回归方法通常隐式依赖生成模型本身来保留此类信息，导致超出活跃上下文后出现空间记忆衰减。我们提出 World-T3，一种相机控制的视频世界模型，其测试时训练记忆将过去观察整合到专用模型参数中。为稳健地更新该记忆，我们提出一种递归最小二乘规则，通过在线以位姿为键的记忆更新来增量吸收新的视觉特征。我们的 TTT 记忆根据相机位姿从快速权重状态中读出先前观察到的场景特征，从而在存储恒定且单步计算量与 rollout 长度无关的情况下实现一致生成。为利用这一稳健记忆促进实时交互生成，我们进一步通过双教师分布匹配将自回归模型蒸馏为少步生成器。在长时程重访基准上，相对于两项指标均最强的基线，World-T3 将重访 PSNR 从 13.52 提升至 18.31 dB，并将绝对旋转误差从 3.344 降至 1.075，同时在单块 NVIDIA B200 GPU 上以 1280 x 704 分辨率保持 20.6 FPS。

## Abstract
Recent advances in video world models have enabled plausible interactive environments, yet long-horizon generation places a fundamental demand on visual memory: the previously observed world must remain consistent as the model continues to generate. Existing autoregressive approaches often implicitly rely on the generative model itself to retain such information, leading to spatial memory decay beyond the active context. We introduce World-T3, a camera-controlled video world model with a test-time training memory that consolidates past observations into dedicated model parameters. To robustly update this memory, we propose a recursive least-squares rule that incrementally absorbs novel visual features via online pose-keyed memory updates. Our TTT memory reads out previously observed scene features from the fast-weight state by camera pose, enabling consistent generation with constant storage and per-step computation regardless of rollout length. To facilitate real-time interactive generation with this robust memory, we further distill the autoregressive model into a few-step generator via dual-teacher distribution matching. On a long-horizon revisit benchmark, World-T3 raises revisit PSNR from 13.52 to 18.31 dB and reduces absolute rotation error from 3.344 to 1.075 relative to the strongest baseline on both metrics, while sustaining 20.6 FPS at 1280 x 704 on a single NVIDIA B200 GPU.

- **研究背景**：视频世界模型（Video World Model）以参考图像、文本和 6-DoF 相机轨迹为条件，自回归地生成可交互环境，是具身仿真、可玩环境生成和虚拟探索的重要接口。
- **核心痛点**：现有自回归视频扩散模型在短时程内局部连贯，但一旦早期观测滑出活跃上下文窗口，模型便会依赖生成先验“重新幻想”场景内容，导致**空间记忆衰减**。当相机回到此前访问过的视角时，场景布局、物体身份和外观发生漂移。
- **现有方案的困境**：
  - 维护显式 3D 场景表示、检索历史帧或压缩记忆 token 虽能提升长时程一致性，但存储开销随 rollout 增长，注意力复杂度也持续上升。
  - 固定容量记忆 token 则会随着新内容压缩而稀释早期观测。
- **论文主张**：将历史观测整合进**在线更新的参数化记忆**（测试时训练，TTT），使记忆存储和每步访问成本与 rollout 长度无关，同时保留对旧场景内容的召回能力。整体含义是：把“持久世界状态”从上下文窗口转移到模型快速权重中，为实时长时程交互式世界模型提供一条新路径。

## 2. 方法论

### 2.1 核心思想

- 将每个生成块视为“相机位姿—视觉内容”的键值关联；块被逐出上下文窗口时，通过闭式在线更新写入 TTT 快权重记忆；后续生成以目标相机位姿为键，从记忆中读出历史场景特征并注入 DiT。
- 记忆由固定投影层 \(W_1\) 和动态读出矩阵 \(W_2\) 构成：键来自相机 Plücker raymap，值来自干净 latent，记忆操作与扩散噪声解耦。
- 由于 \(W_1\) 固定、\(W_2\) 通过递归最小二乘（RLS）更新，记忆状态在任意时刻都是加权岭回归目标的精确最小化器，且与观测顺序无关。

### 2.2 三阶段训练流程

- **Stage 1：双向相机条件教师**
  - 基于预训练视频扩散模型 Wan2.2-TI2V-5B，冻结主干，仅训练秩 256 的 LoRA 适配器（所有注意力与 FFN 投影）和秩 512 的相机调制模块 CamAdaLN。
  - 使用 Plücker raymap 编码相机几何：对每帧的旋转 \(R_f\)、相机原点 \(o_f\) 和内参 \(K\)，射线方向 \(d_{f,uv}\propto R_fK^{-1}[u,v,1]^\top\)，六维表示为 \((d_{f,uv}, o_f\times d_{f,uv})\)，形成与 latent 网格对齐的六通道场。
  - 相机特征通过自适应 layer-norm 注入每个 DiT 块，零初始化输出投影保证训练稳定。
  - 双向注意力使教师具备全局几何与运动一致性，为 Stage 2 提供初始化、为 Stage 3 提供参考 score。

- **Stage 2：带 TTT 记忆的自回归教师**
  - 将双向模型转为块因果自回归：生成序列分为 \(N\) 个 latent 块 \(x_{1:N}\)，每块含 \(B\) 个 latent 帧；联合分布按块因果分解：
    \[
    p_\theta(x_{1:N}\mid T_{1:N},c_I,c)=\prod_{b=1}^N p_\theta(x_b\mid C_b,M_b,T_{1:b},c_I,c)
    \]
  - **有界视觉上下文** \(C_b=[s;x_{b-K:b-1}]\)：第一块 \(s=x_1\) 作为持久 sink 锚定长期外观，滑动窗口保留最近 \(K\) 个干净块提供局部连续性。训练采用掩码 teacher forcing，块因果掩码阻止目标块关注未来块。
  - **TTT 记忆写入**：当块 \(e_j\) 被逐出上下文时，构造键值：
    \[
    k_j=\phi_K(\Pi_{e_j}),\quad v_j=\phi_V(h_{e_j})
    \]
    其中 \(\Pi_{e_j}\) 为相机 raymap，\(h_{e_j}\) 为干净隐状态。
  - **递归最小二乘更新**：将记忆整合建模为加权岭回归：
    \[
    \min_{W_2}\sum_{i\le j}w_i\|v_i-W_2\phi_i\|^2+\lambda\|W_2-W_2^{(0)}\|_F^2
    \]
    其中 \(\phi_j=\mathrm{gelu}(W_1k_j)\)。递归跟踪逆正则化特征相关矩阵 \(P_j=(\sum_{i\le j}w_i\phi_i\phi_i^\top+\lambda I)^{-1}\)，每步更新：
    \[
    g=\frac{P\phi}{w^{-1}+\phi^\top P\phi},\quad
    W_2\leftarrow W_2+(v-W_2\phi)g^\top,\quad
    P\leftarrow P-g\phi^\top P
    \]
    \(P\phi\) 作为白化预条件器，抑制已由历史记忆张成的方向，使每次写入只吸收新颖残差；\(\lambda=10^{-3}\)，\(P_0=I/\lambda\)。
  - **记忆读取与注入**：目标块 \(b\) 的位姿键 \(k_b=\phi_K(\Pi_b)\)，读出 \(m_b=W_2\,\mathrm{gelu}(W_1k_b)\)，经输出投影和逐通道门控 \(\gamma\) 以残差注入：
    \[
    h_b\leftarrow h_b+\gamma\odot W_{\text{out}}m_b
    \]
  - **外层循环学习**：TTT 模块与 DiT 联合训练，梯度穿过 RLS 递归更新，优化 \(W_1\)、\(W_2^{(0)}\)、键/值编码器、样本权重 \(w\) 和门控 \(\gamma\)；部署时仅 \(W_2\) 和 \(P\) 在线演化，不反传扩散 Transformer。

- **Stage 3：双教师少步蒸馏**
  - 先用一致性蒸馏将连续 flow matching 离散为 4 步采样。
  - 再用双教师分布匹配蒸馏（DMD）恢复视觉质量与长期记忆：
    - **双向教师 score** \(s_{\text{bidir}}\)：Stage 1 教师，约束短程视觉真实感与运动连贯。
    - **记忆增强自回归教师 score** \(s_{\text{mem}}\)：Stage 2 教师，沿长 rollout 评估，保持长时程空间一致性。
  - 每个教师配一个架构同构的 critic，学生生成器梯度为两项 DMD 梯度之和：
    \[
    \nabla_\theta L_{\text{DMD}}=\nabla_\theta L_{\text{DMD}}(\text{teacher}_{\text{bidir}},\text{critic}_{\text{bidir}})
    +\nabla_\theta L_{\text{DMD}}(\text{teacher}_{\text{mem}},\text{critic}_{\text{mem}})
    \]
    每项通过教师与 critic 的 score 差乘以生成器 Jacobian 计算。记忆教师的记忆状态由学生自身 rollout 初始化，以惩罚累积轨迹漂移。

## 3. 实验设计

### 3.1 数据与 Benchmark

- **训练语料**：908K 条带相机标注的片段，其中 601K 基础片段 + 307K 重访增强片段；混合真实世界视频与游戏引擎合成渲染，统一为 1280×704、16 FPS。相机位姿由 VGGT-Ω 提取，并以首帧为世界原点。
- **重访构建**：对静态场景采用片段回放（loop and re-index）制造周期性回到旧视角；合成数据设计闭环相机轨迹。
- **评测 Benchmark**：自建 120 条 out-and-back 相机轨迹片段，每条 160 帧（10 秒 @16 FPS），第 80 帧相机反向。选取四对出程/回程帧 \((8,152),(16,144),(24,136),(32,128)\)，对应 36/32/28/24 个 latent 帧的时间间隔，均超过 21 帧活跃上下文窗口。
- **评测指标**：
  - 重访保真度：DINOv2 语义相似度、PSNR、SSIM、LPIPS，以及 GT 参考距离的首次访问—回访退化量 \(\Delta\)。
  - 相机跟随：绝对旋转误差 RotErr、相机矩阵误差 CamMC、连续帧旋转/平移相对位姿误差 RPE。
  - 视觉质量：VBench 七维平均（成像质量、美学质量、主体一致性、背景一致性、运动平滑度、时间闪烁、整体一致性）。
  - 局部时序一致性：Local Memory（LM），基于 TransNetV2 场景切分与 DINOv2 突变检测。
  - 效率：单卡/多卡 FPS、端到端延迟、峰值显存。

### 3.2 对比方法

- 五个近期视频世界模型：**Matrix-Game 3.0、HY-World 1.5、DreamX-AR、LingBot-Fast、SANA-WM**，均使用官方 checkpoint 与代码。
- 同时评估 World-T3 的 **Stage 2 自回归教师（50 步）** 与 **Stage 3 少步学生（4 步）**。
- 所有方法使用相同初始帧、文本提示和规定 6-DoF 相机轨迹。

### 3.3 主要实验组

- 主表：重访保真度、相机跟随、VBench、FPS、峰值显存对比。
- 相机 sweep 分层：按 yaw sweep/FOV 将 120 条片段分为 T1–T3 三个 40 条层级，比较重访相似度随 sweep 增大的退化。
- 互补重访指标表：DINO 自距离、GT 参考距离、Self-SSIM、GT-SSIM、LM。
- 蒸馏前后教师—学生对比：重访 PSNR、LPIPS、DINO 距离、相机指标、VBench、LM。
- 统计检验：120 条片段上的配对精确双侧符号检验。
- 效率优化累计消融：10 项优化逐步叠加，报告端到端延迟、FPS、显存。
- 数值保真测试：算子级与 rollout 级对比 FP32 参考。
- 多 GPU 效率对比：单卡与 8 卡设置。
- 定性结果：室内/室外 out-and-back 轨迹，以及 30 秒真实相机运动中的近似重访。
