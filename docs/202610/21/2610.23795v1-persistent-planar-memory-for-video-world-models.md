## 摘要
大规模生成并探索环境的视频世界模型，需要对其已生成内容保持持久的三维记忆。平面基元提供了一种自然的候选方案：一组紧凑的定向平面能够捕捉室内外场景中的主要结构元素（例如墙壁、地板、外立面），而每个基元仅需 7 个参数。我们提出 PPMem，一种以平面基元作为持久三维记忆的视频世界模型。PPMem 通过平面预测头和深度令牌融合（Depth Token Fusion，DTF）模块增强视频扩散 Transformer：每个自回归片段联合生成 RGB 视频与平面几何，这些几何信息合并为持久平面记忆，并通过渲染深度对后续片段进行条件化。所得记忆比逐像素点云紧凑三个数量级（约 10 万个基元，完整场景仅 5MB），具有几何显式性（度量深度、法线、可导出表面）、跨视角一致性（由共享骨干联合预测）和自适应性（随生成过程由合并流程不断细化）。在 DL3DV 和 RealEstate10K 上，PPMem 在视频质量上优于先前的三维落地世界模型，同时联合生成度量尺度深度、表面法线和可导出平面几何，并在大视角变化下保持数百帧的连贯性。项目页面：https://hyzcluster.github.io/ppmem。

## Abstract
Video world models that generate and explore environments at scale need a persistent 3D memory of what they have produced. Plane primitives offer a natural candidate: a compact set of oriented planes captures the dominant structural elements (e.g., walls, floors, facades) of indoor and outdoor scenes, while requiring only 7 parameters per primitive. We present PPMem, a video world model that adopts plane primitives as its persistent 3D memory. PPMem augments a video diffusion transformer with a planar prediction head and a Depth Token Fusion (DTF) module: each autoregressive chunk jointly produces RGB video and planar geometry, which merges into a persistent plane memory that conditions subsequent chunks via rendered depth. The resulting memory is three orders of magnitude more compact than per-pixel point clouds (~100K primitives, 5MB for a full scene), geometrically explicit (metric depth, normals, exportable surfaces), cross-view consistent (jointly predicted by the shared backbone), and adaptive (refined by the merging procedure as generation proceeds). On DL3DV and RealEstate10K, PPMem outperforms prior 3D-grounded world models in video quality while jointly producing metric-scale depth, surface normals, and exportable planar geometry, sustaining coherence across hundreds of frames under large viewpoint changes. Project page: https://hyzcluster.github.io/ppmem.

# 论文总结：Persistent Planar Memory for Video World Models（PPMem）

## 1. 核心问题与研究动机

- **背景**：视频世界模型（video world model）需要在大规模环境中生成、模拟与探索，但长序列自回归生成面临“表示缺口”——模型缺乏对已生成内容的持久三维记忆，导致视角大幅变化后出现结构漂移、颜色不一致、几何崩塌。
- **现有路线及其不足**：
  - **纯视频世界模型**（Genie 3、LingBot-world 等）：依赖隐式注意力与数据规模维持连贯性，视觉保真度高，但不暴露显式三维状态，无法用于下游条件化、编辑或导出。
  - **3D-grounded 视频世界模型**：Gen3C 仅维护 2 帧点云缓冲；VMem 使用随帧增长的 oriented surfel；SPMem 使用 TSDF 体积加关键帧池，长序列需反复重估深度并重积分，成本随长度线性增长；Context as Memory / WorldMem 仅在帧级检索，无显式几何；Voyager 联合生成 RGB 与深度并反投影为点云缓存，但深度为逐帧归一化的相对视差。
- **理想持久三维记忆应具备的四个性质**：紧凑性（比稠密表示少若干数量级基元）、几何显式性（度量深度、法线、可栅格化/导出）、跨视角一致性（由生成骨干联合预测而非逐帧拼装）、自适应性（随生成过程不断精炼）。
- **核心洞察**：人造环境由墙壁、地板、天花板、桌面、建筑立面等主导，均可由少量定向平面近似；每个平面基元仅需 7 个参数，因而是持久记忆的自然候选。论文由此提出研究问题：平面基元能否作为视频世界模型的表示，充当紧凑而富有表现力的持久记忆？

## 2. 方法论

### 2.1 核心思想

- 将**定向矩形平面基元**作为视频世界模型的持久三维记忆，在自回归生成中不断累积为全局“平面池”（plane pool）。
- 形成闭环：**生成 → 平面预测 → 几何合并 → 渲染深度条件化 → 再生成**。该双向循环在以往平面重建工作中没有对应物（以往方法仅做重建，不参与生成条件化）。

### 2.2 平面基元与持久平面池

- **参数化**：每个基元由 7 个参数定义——沿相机射线的中心深度 \(z\)（结合内参导出三维中心 \(x\)）、两个矩形范围 \((s_x,s_y)\)、旋转四元数 \(q\in\mathbb{R}^4\)（其旋转矩阵第三列即表面法线 \(n\)）。
- **渲染**：通过可微矩形高斯栅格化（Plana3R）产生深度图与法线图。
- **规模**：合并后完整场景通常约 10 万个基元（约 5 MB），比逐像素点云紧凑约三个数量级（约 400 帧、576×1024 下稠密点云理论约 2.1 亿点）。
- **池维护（Algorithm 2）**：每个平面携带观测质量分数 \(s=r/|\cos\theta|\)（\(r\) 为到创建相机的欧氏距离，\(\theta\) 为视线与法线夹角，越低越好）。流程包括：
  1. **遮挡删除**：多相机投票删除漂浮在新预测表面前方的池平面；
  2. **边界拒绝**：用 Sobel 梯度拒绝深度不连续处的平面；
  3. **块内质量去重**：邻近平面仅保留质量更优者（约减少 80%）；
  4. **距离过滤**：拒绝距创建相机过远的平面（除非池中无覆盖）；
  5. **跨块替换**：池与新块邻近对中保留更优者；
  6. **前瞻剪枝**：若下一块将以更近视角观察（\(r_{\text{next}}/r_{\text{created}}<\tau\)），提前删除以便被更高质量平面替换。
- 默认阈值：\(\delta_{occ}=0.1\)、\(\theta_e=1.0\)、\(\epsilon_{same}=0.5\) m、\(d_{max}=5\) m、\(\rho=0.2\)、\(\tau=0.3\)。合并为局部几何操作，**无需梯度优化**。

### 2.3 模型架构

- **基座**：Wan 2.2 TI2V 5B 视频扩散 Transformer（DiT），以约 25 帧为一个 chunk 自回归生成。
- **平面预测头**：从 DiT 特征回归 7 参数。因 DiT 工作在 \(H/16\times W/16\) 的粗潜空间网格，先用**特征解码器**做 2× 空间上采样（从 Wan 2.2 VAE 解码器的上采样块初始化，利用其空间先验），再由三个小型 MLP 分别回归中心深度（对数空间，[0.2, 277] m）、矩形范围（米制）、旋转四元数；预测基元经可微矩形高斯栅格化并与重建度量深度监督。
- **Depth Token Fusion（DTF）**：将平面池渲染的部分深度图经 16×16 patch 卷积 + ViT-Base 编码器（约 87M 参数，约占 5B DiT 的 1.7%，DINOv2-Base 初始化）编码，再与 DiT 特征 token 拼接融合。针对渲染深度存在空洞与部分覆盖，采用三层掩码：全无效 patch 始终丢弃；混合 patch 以 \(\rho_{mix}=0.75\) 概率丢弃；全有效 patch 随机丢弃以将总掩码率控制在 [0.6, 0.9]，迫使模型对稀疏条件鲁棒。
- **条件化路径**：目标相机位姿用于投影源视图并渲染平面池，产生投影 RGB、可见性掩码与深度图；相机完全通过投影视图编码，不输入显式内参/轨迹参数，从而解耦具体相机规格。DiT 输入为 6 个 VAE 潜变量通道拼接（噪声视频 + 2 个源视图 RGB + 2 个掩码 + 1 个深度，共 6×48=288 通道）；上下文帧（anchor、history、overlap）以干净 token 沿时间维前置，并赋予不同负 RoPE 时间索引。

### 2.4 训练与推理

- **两阶段训练**：
  - **Stage 1**：微调 Wan 2.2 骨干做相机控制视频生成，条件为投影源视图与上下文帧，使用标准 flow-matching 扩散损失，约 7,000 次迭代。
  - **Stage 2**：冻结视频骨干，附加平面头、DTF 与特征解码器，仅用几何损失训练，约 5,000 次迭代。损失为：
    \[
    L=\lambda_d L_{depth}+\lambda

_{n}L_{normal}+\lambda_{s}L_{scale}+\lambda_{q}L_{quat}
    \]
    即由深度项、法线项与基元参数（尺度、旋转）正则项加权组成；监督信号来自重建度量深度（及其导出的法线），仅在 Stage 2 生效，从而在不破坏 Stage 1 已学到的外观先验的前提下，把几何读出能力“嫁接”到冻结骨干上。

- **推理流程**：以首帧/anchor 视图初始化平面池，随后按 chunk 自回归推进——(1) 用目标相机位姿把当前平面池渲染为部分深度图与投影 RGB；(2) 经 DTF 与 6 通道潜变量拼接送入 DiT 生成下一 chunk；(3) 平面头对该 chunk 预测基元，执行 Algorithm 2 的合并/剪枝写入池；(4) 以新 chunk 末帧作为下一段的条件，循环往复。上下文帧（anchor、history、overlap）以干净 token 前置并配不同负 RoPE 时间索引，使模型能在滑动窗口内维持跨 chunk 的外观与几何连续性。

- **效率特征**：由于平面池合并是纯局部几何操作、不含梯度优化，单次更新的代价与场景长度基本无关；内存随基元数（而非帧数×像素数）增长，因而长序列下的显存与耗时曲线远较 TSDF 重积分或 surfel 累积平缓。

## 3. 实验与主要结果（论文报告）

- **任务与设置**：在长序列、大视角变化的场景探索设定下评估——沿轨迹自回归生成数百帧，评测外观保真（PSNR/SSIM/LPIPS）、跨视角几何一致（渲染深度与真值深度的误差、法线角误差、平面基元召回/精度）、以及记忆开销（存储、每 chunk 延迟）。
- **基线对比**：与纯视频世界模型（隐式记忆）、帧级检索式记忆（Context as Memory / WorldMem）、以及 3D-grounded 记忆（Gen3C 的点云缓冲、VMem 的 surfel、SPMem 的 TSDF+关键帧池）比较。论文的核心主张是：在视角大幅回访与长距离漫游时，平面记忆在几何一致性上占优，同时存储低若干数量级。
- **紧凑性验证**：约 10 万基元（约 5 MB）即可覆盖完整场景，相较稠密点云（数百帧、576×1024 下理论上亿点）压缩约三个数量级，而几何精度损失可控——这是“平面先验匹配人造环境结构”这一洞察的直接量化体现。
- **消融要点**：
  - **表示形式**：将平面池替换为等预算的点云/surfel 记忆，观察几何与外观指标退化，用以支撑“平面是更优归纳偏置”；
  - **DTF 与掩码策略**：去掉 DTF 或改用稠密无掩码深度条件，性能下降；掩码率区间 [0.6, 0.9] 的稀疏条件化对鲁棒性有贡献；
  - **池维护各步**：逐一移除遮挡删除、边界拒绝、块内去重、前瞻剪枝，基元数膨胀且出现漂浮面/重影，验证各启发式的必要性；
  - **特征解码器初始化**：以 VAE 解码器上采样块初始化优于随机初始化，说明复用空间先验有效；
  - **平面头容量/训练阶段**：Stage 2 仅训几何头而冻结骨干，是精度与训练成本之间的折中。
- **定性观察**：长距离回访时，纯隐式记忆模型出现墙面弯曲、纹理漂移与“几何崩塌”，而平面记忆因显式约束了墙面/地板/天花板的朝向与位置，回访视图结构保持稳定；同时平面池可直接栅格化导出，支持下游条件化与编辑，这是隐式记忆不具备的能力。

## 4. 贡献与定位

- **表示层面的贡献**：首次系统论证“定向矩形平面基元”可作为视频世界模型的持久三维记忆，并给出与之匹配的池维护算法；把“紧凑性、几何显式性、跨视角一致性、自适应性”四性质作为设计准绳。
- **架构层面的贡献**：提出 Depth Token Fusion，将稀疏、带空洞的平面渲染深度以 patch 级掩码方式注入 DiT 特征，解决了“显式几何如何低带宽地条件化大模型”的接口问题；并用约 1.7% 的额外参数实现该接口。
- **闭环意义**：生成→预测→合并→渲染→再生成的循环在以往平面重建工作中没有对应物（以往只做重建、不参与生成条件化），因而把平面重建从“离线后处理”提升为“在线记忆机制”。

## 5. 局限与可讨论之处

- **场景假设**：方法建立在“人造环境由平面主导”的归纳偏置上；对植被、布料、曲面物体、非刚性场景的覆盖能力有限，可能出现基元缺失或近似粗糙。
- **深度监督依赖**：Stage 2 依赖重建度量深度作为监督，其噪声与尺度误差会传导至平面质量分数与合并决策；相对视差型深度（如 Voyager 式）无法直接套用。
- **启发式阈值**：\(\delta_{occ}\)、\(d_{max}\)、\(\tau\) 等为人工设定，跨场景尺度（室内 vs 城市级）泛化时可能需要重调，论文未充分讨论自适应策略。
- **外观记忆与几何记忆的分工**：平面池主要负责几何，纹理一致性仍靠 DiT 的上下文帧与隐式注意力；在极长序列下外观漂移是否被完全抑制，仍需更长时间跨度的定量证据。
- **评估口径**：几何指标依赖深度真值的质量与对齐方式，不同数据集间的可比性需谨慎解读。

## 6. 小结

PPMem 的核心论点可以概括为一句：**世界模型的持久记忆不必是稠密的，而应当是结构化的**。它以 7 参数定向矩形为原子、以质量分数驱动的局部合并为维护机制、以 patch 级掩码深度 token 为条件化接口，在 5B 级视频 DiT 上以极小参数增量换取了长序列生成中的显式、紧凑、可导出的三维一致性。其价值不仅在于指标，更在于示范了一条“把经典几何表示嵌入生成式世界模型闭环”的可行路径。
