## ABSTRACT 

Post-training is crucial for improving text-to-image models, yet existing pipelines typically rely on manually curated training data and fixed training distributions. We introduce APT (Agentic Post-Training), a fully automated framework that adaptively post-trains a base model according to its evolving capability profile. APT coordinates three agents to construct evaluation sets from user requirements, diagnose model-specific strengths and failure modes, and generate reinforcement learning data with an adaptive prompt distribution that emphasizes underperform-ing capabilities. By repeatedly evaluating, diagnosing, and updating the generator, APT lets the current model’s behavior shape its next training tasks, forming a feed-back loop inspired by recursive self-improvement. For general-purpose settings without user-specified evaluation scenarios, we further develop an evaluation har-ness that enables broad and diverse evaluation set generation. Experiments across multiple base models, benchmarks, and generation architectures demonstrate that APT is model-agnostic, benchmark-agnostic, architecture-agnostic, and fully au-tomated.

1arXiv:2610.18097v1 [cs.CV] 13 Oct 2026 1 INTRODUCTION 

Recent text-to-image (T2I) models have achieved remarkable progress in visual quality, prompt following, text rendering, compositional generation, and controllability (Black Forest Labs, 2025; OpenAI, 2026; Google, 2026; SeedDance, 2026; Zhao et al., 2026). Beyond large-scale pre-training, post-training has become increasingly important for correcting specific failure modes and aligning model behavior with desired objectives (Xu et al., 2026; Chen et al., 2026a; Jiang et al., 2026a; Feng et al., 2026b). Existing post-training pipelines, however, typically rely on manually constructed training distributions: practitioners identify model weaknesses, collect or synthesize corresponding training data, and repeatedly adjust the data distribution based on empirical observations (Xu et al., 2026; Chen et al., 2026a; Feng et al., 2026b; Geng et al., 2025). Such a workflow is labor-intensive and difficult to scale as models, benchmarks, and user requirements continue to diversify. More fundamentally, we argue that post-training should be model-adaptive . Different base models exhibit substantially different capability distributions: a model that performs well on text rendering may struggle with counting or spatial relations, while another may exhibit the opposite behavior. Consequently, a post-training dataset that is effective for one model is not necessarily optimal for another. We can view each base model M as inducing its own capability and failure distribution pM

over generation tasks. Effective post-training should therefore identify where the current model un-derperforms, sample training examples accordingly (Chen et al., 2026b), and continuously adapt the sampling distribution as the model improves (Li et al., 2026). In other words, the key question is not only how to optimize a model , but also what the current model should be trained on . This perspec-tive naturally connects post-training to recursive self-improvement (RSI), in which the evaluation results of the updated model are used to determine the training tasks for the next round (Zelikman et al., 2023; Zweiger et al., 2026; Huang et al., 2026). To address this problem, we introduce APT (Agentic Post-Training) , a fully automated framework that turns post-training into an adaptive, evaluation-driven self-improvement loop, as illustrated in Figure 1. Given a T2I base model and an evaluation requirement, APT automatically constructs an evaluation set of prompt–rubric pairs, diagnoses the current model’s strengths and weaknesses, and generates model-specific RL training data. The updated model is then re-evaluated, allowing its evolving behavior to continuously reshape the training distribution for the next round. Rather than relying on a fixed, manually curated dataset, APT lets the current model determine what should be learned next. As shown in Figure 1, APT is built around three collaborative agents. The Evaluation Set Generation Agent converts a high-level evaluation scope into a structured evaluation suite with an adaptive tax-onomy, prompts, and task-specific rubrics. The Diagnosis Agent evaluates the current model at the instance and category levels and summarizes systematic strengths and failure modes. The RL Data Generation Agent then converts this diagnosis into an adaptive prompt distribution that prioritizes underperforming capabilities while retaining moderate and mastered ones, producing model-specific data for RL-based post-training (Zheng et al., 2026; Liu et al., 2026a; Shao et al., 2024). Repeated evaluation, diagnosis, and adaptive sampling provide an implicit mechanism for discovering and tracking the evolving model-dependent distribution pM without explicitly estimating it. APT also supports general-purpose post-training when no evaluation scope is specified. For this setting, we develop an evaluation harness that guides the Evaluation Set Generation Agent to sys-tematically construct a broad and diverse evaluation set spanning common generation scenarios and capability dimensions (Feng et al., 2026c). The resulting framework is model-agnostic , benchmark-agnostic , architecture-agnostic , and fully automated , and we validate these properties across multiple T2I models, generation architectures, and benchmarks (Chen et al., 2026a; Esser et al., 2024; Black Forest Labs, 2024; Team et al., 2025; Chen et al., 2025). APT consistently improves diverse base models and outperforms post-training with a carefully handcrafted RL training set. Moreover, transferring APT-generated training data across models is consistently inferior to adaptively generating data for the target model, supporting our central hypothesis that effective post-training distributions are model-specific and should evolve together with the model. Together, these results establish agentic, evaluation-driven adaptation as a practical step toward recursive self-improvement for text-to-image generation. 22 METHOD 

Overview. Figure 1 provides an overview of APT. The Evaluation Set Generation Agent is invoked once before post-training to construct the fixed evaluation set E of prompt–rubric pairs (Section 2.1). Users may specify an evaluation scope; when no scope is provided, we use our general-purpose evaluation harness to ensure broad and comprehensive coverage. APT then enters an iterative post-training loop. At each round, the Diagnosis Agent (Section 2.2) evaluates the current model and produces an evaluation report, which is passed to the RL Data Generation Agent (Section 2.3) to generate training data for the next RL update. This RSI-inspired loop repeats after each update, enabling the training distribution to adapt to the model’s evolving weaknesses. As described in Sec-tion 2.4, APT is model-agnostic, benchmark-agnostic, and architecture-agnostic, and can therefore be applied to diverse text-to-image models and evaluation settings.

As a result, each evaluation ex-ample is represented as a prompt paired with its corresponding rubrics, enabling fine-grained and task-aware diagnosis of model behavior. The RL Data Generation Agent takes the evaluation report produced by the Diagnosis Agent as input and generates training prompts for the subsequent RL update. Its main role is to identify recurring failure patterns in the report, summarize the capabilities that should be improved, and translate these findings into a model-specific training distribution. We use the evaluation report as an empirical characterization of the current model’s capability dis-tribution. This is feasible for several reasons. First, the evaluation set is designed to provide broad coverage over diverse generation scenarios and capabilities. As a result, the sampled evaluation examples probe many different regions of the model’s capability space rather than concentrating on a narrow benchmark-specific domain. Second, each prompt is associated with multiple prompt-specific rubrics, which provide fine-grained feedback on what the model succeeds or fails on. There-fore, the report contains not only whether a generation is successful, but also structured evidence about the underlying capability responsible for the success or failure. Third, modern language mod-els such as GPT-5.4 have strong summarization and reasoning capabilities, allowing them to com-pare observations across many evaluation examples and identify recurring patterns that may not be obvious from any individual sample. For instance, prompts from different semantic categories may repeatedly fail for the same underlying reason, such as accurate counting, rendering text on objects, or preserving specific attributes. By aggregating these cross-example patterns, the agent can infer which capabilities are consistently underperforming and which are already handled reliably. Finally, because the evaluation report is regenerated from the current model at every post-training round, the inferred capability profile naturally changes as the model improves. In this sense, the Diagnosis Agent and RL Data Generation Agent together provide an implicit and continually updated estimate of the model’s current performance distribution, without requiring an additional explicitly trained estimator. APT is designed as a general post-training framework that can be applied across different evaluation settings, base models, and generation architectures without task-specific or model-specific redesign. Specifically, APT is (1) benchmark-agnostic : it does not require independently designed prompt sets for individual benchmarks, and a single APT run can be evaluated across multiple T2I benchmarks; (2) model-agnostic : the same agentic workflow can be directly applied to diverse base models, including Lens (Chen et al., 2026a), SD3.5 (Esser et al., 2024), FLUX (Black Forest Labs, 2024), and LongCat-Image (Team et al., 2025); (3) architecture-agnostic : APT is not tied to a particular image-generation formulation and is effective for both diffusion-based and autoregressive image-generation models (Chen et al., 2025; Sun et al., 2024); and (4) fully automated : the evaluation results of the current model directly drive the generation of prompts for subsequent RL updates, eliminating the need for manually inspecting failures, designing training distributions, or curating model-specific post-training data (Xu et al., 2026; Geng et al., 2025). 

Recursive Self-Improvement for Text-to-Image Generation. APT brings recursive self-improvement (RSI) (Zelikman et al., 2023; Zweiger et al., 2026) to text-to-image generation by making the generator’s evolving capabilities drive the construction of its own training curriculum. As formalized in Equation 2, the current model produces behavioral evidence that agents translate into targeted training tasks; RL updates the generator on these tasks, and the updated generator pro-vides fresh evidence for the next round. This creates a recursive coupling between model optimiza-tion and task construction: learning changes the model’s capability profile, which in turn changes what the system trains on next. Through this feedback loop, APT continually revises its training priorities in response to the generator’s remaining and newly exposed weaknesses. By automat-ing diagnosis, curriculum construction, and RL updates, APT turns the generator’s own successes and failures into actionable signals for directing subsequent improvement. APT thus operationalizes RSI for T2I post-training through an adaptive curriculum that evolves alongside the model, replacing manual intervention in deciding what the model should learn next. 

## 3 EXPERIMENTS 

3.1 EXPERIMENTAL SETUP 

Base T2I Models. To demonstrate that APT is model-agnostic, we apply it to four diffusion-based T2I models: Lens (Chen et al., 2026a), SD3.5-Medium (Esser et al., 2024), FLUX.1 [dev] (Black Forest Labs, 2024), and LongCat-Image (Team et al., 2025). We further evaluate whether APT generalizes across model architectures by applying it to the autoregressive image generator Janus-Pro (Chen et al., 2025). We use the same APT agentic workflow across all models, without intro-ducing any model-specific prompt sets, reward designs, or hyperparameter searches. 

Benchmarks and Metrics. We evaluate on five widely used text-to-image benchmarks that jointly cover compositional generation, prompt following, and text rendering: GenEval (Ghosh et al., 2023), GenEval2 (Kamath et al., 2025), OneIG-EN (Chang et al., 2026), DPG (Hu et al., 2024), and CVTG-2K (Du et al., 2025). Details of each benchmark are provided in Section C. Since the benchmark scores are reported on different scales, we additionally report a normalized average by rescaling GenEval, OneIG-EN, and CVTG-2K to the [0 , 100] range and then averaging the scores across all five benchmarks. Crucially, none of these benchmarks is used to construct the training prompts :a single APT run produces one post-trained model, which is then evaluated on all five benchmarks, directly testing the benchmark-agnostic nature of APT described in Section 2.4. 

Implementation Details. We use DiffusionNFT (Zheng et al., 2026) as our default RL algorithm for post-training. All models are post-trained with LoRA (rank 64 , α = 128 ), using a learning rate of 3e -4. During rollout, Lens, SD3.5-M, and LongCat-Image use 10 sampling steps, while FLUX.1 [dev] uses 6 steps. The training resolution is 768 × 768 for Lens and SD3.5-M, and 512 × 512 for FLUX.1 [dev] and LongCat-Image. For APT, each training round consists of 20 optimization steps. At the beginning of each round, the Diagnosis Agent samples 120 prompt-rubrics pairs from the evaluation set generated by the Evaluation Set Generation Agent and produces an evaluation report. This report is then fed into the RL Data Generation Agent, which automatically generates 480 RL training prompts for the subsequent training round. Nevertheless, APT con-sistently achieves higher average performance across all four models. Without using benchmark-specific training prompts or tuning, the same post-trained model improves over its base model across most evaluated benchmarks. Note that, for efficiency, we post-train each model for 200 steps in this study.

## 4 CONCLUSION 

We presented APT, a fully automated framework for adaptive post-training of text-to-image models. By coordinating evaluation set generation, model diagnosis, and RL data generation, APT adapts the training distribution to each model’s evolving capabilities. Experiments across multiple mod-els and benchmarks show higher average performance than post-training on handcrafted RL data, while transfer studies and ablations support the value of model-specific training data and iterative feedback. Advances in Neural Information Processing Systems , 38:74084–74115, 2026. 12 A RELATED WORK 

Post-Training for Text-to-Image Generation. Post-training has become a standard paradigm for adapting pre-trained T2I models to downstream objectives. Supervised fine-tuning (SFT) adapts a model to curated image–text pairs, with performance gains largely determined by data filtering, recaptioning, and aesthetic curation, but it remains bounded by the collected corpus and costly hu-man curation. A complementary line directly optimizes downstream rewards following the policy-gradient view of reinforcement learning (Williams, 1992; Schulman et al., 2017): DDPO (Black et al., 2024) formulates denoising as a multi-step decision-making problem and optimizes diffusion models with policy gradients; Diffusion-DPO (Wallace et al., 2024) adapts direct preference opti-mization (Rafailov et al., 2023) to diffusion models, and SPO (Liang et al., 2024) refines it with step-aware preference signals; more recently, Flow-GRPO (Liu et al., 2026a) and follow-ups (Li et al., 2025; Liu et al., 2026b) extend online policy-gradient training to flow matching via stochas-tic sampling, and DiffusionNFT (Zheng et al., 2026) performs negative-aware fine-tuning on the forward process without likelihood estimation. 

Agentic Image Generation. Recent work augments image generation and editing with agentic capabilities such as planning (Yao et al., 2026), reasoning over implicit user intent (He et al., 2026), web and image search for open-world grounding (Feng et al., 2026a), and self-feedback for test-time scaling (Jiang et al., 2026b; Wang et al., 2025), with emerging systems unifying these abilities in a single framework (Zhang et al., 2026b). These methods share a common design: the agent operates at inference time around a frozen gener-ator , improving how a fixed model is used rather than changing the model itself. As a result, intrinsic failure modes persist once the agentic scaffolding is removed, and every deployment pays the ex-tra inference cost. APT instead moves the agent from the inference loop into the post-training loop: discover model weaknesses through evaluation and address them through training. The gains are ab-sorbed into the model parameters and retained under standard single-pass inference, and the training distribution is re-derived from the current model at every round, making APT model-adaptive rather than applying one fixed agentic policy to any generator. The two directions are thus complementary: prior work makes better use of a given model, while APT makes the model itself better.
