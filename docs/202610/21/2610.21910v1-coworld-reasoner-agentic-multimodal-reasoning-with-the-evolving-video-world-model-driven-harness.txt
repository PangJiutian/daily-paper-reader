Abstract
As Vision-Language Models (VLMs) advance, they are increasingly expected to perform spa-
tiotemporal reasoning over motion, actions, and view changes beyond what the input images
show. Video World Models (VWMs) provide a natural unified engine for visual imagination by
generating task-relevant visual content as additional evidence. However, existing approaches typ-
ically invoke a VWM through fixed pipelines centered on a predefined form of visual imagination,
such as novel-view synthesis. To support flexible visual imagination for diverse reasoning tasks,
we introduce CoWorld Reasoner, an agentic framework that uses a VWM as a unified visual
reasoning engine. Its Video World Model-Driven Harness exposes multiple visual operations
through tools and uses skills to guide the VLM in deciding whether to imagine, selecting an
operation, constructing a generation request, and interpreting the resulting visual evidence.
We further introduce VLM-VWM Harness Co-Evolution, which jointly revises tools, skills, and
execution code based on execution feedback while keeping both model weights fixed. Across
seven benchmarks spanning spatial intelligence, temporal and causal reasoning, and perceptual
reasoning, CoWorld Reasoner outperforms direct reasoning with the same VLM. The strongest
variant improves on all seven benchmarks, including relative accuracy gains of 11.8% on MMSI
and 13.0% on ERQA, and outperforms all five evolving baselines using the same backbone across
five benchmarks.

1 Introduction
Large Language Models (LLMs) have demonstrated strong instruction-following and reasoning
abilities, but they operate primarily over text. Vision-Language Models (VLMs) extend these
capabilities to visual inputs, enabling multimodal understanding and reasoning. Recent VLMs
such as Qwen3.8 [1] and Gemini 3.8 [2] can effectively interpret images and analyze charts, and
they are increasingly used in real-world multimodal applications.
Beyond static image understanding, VLMs are increasingly expected to perform spatiotemporal
reasoning over motion, actions, and view changes. For example, a model may need to predict
whether two objects would overlap if one were moved, reconstruct what happened between two
observations, or infer what another viewpoint would reveal. Solving such problems requires
going beyond observed visual evidence to reason about unobserved transitions and relations. One
promising approach is visual imagination: explicitly generating task-relevant visual predictions

Video World Models (VWMs), such as MiniMax H3 [3] and LTX-Video [4], provide a natural
engine for visual imagination by modeling visual dynamics from large-scale video data. Given
input images and an appropriate visual operation, they can generate video depicting unobserved
views, intermediate states, future events, or intervention outcomes. Recent approaches, including
MindJourney [5] and AVIC [6], use a VWM to generate additional visual evidence for spatial rea-
soning, including synthesized views for cross-view reasoning. However, these approaches typically
invoke a VWM through fixed pipelines centered on a predefined form of visual imagination, such
as novel-view synthesis. This limits their applicability to diverse reasoning problems, which may
require fundamentally different forms of visual imagination: changing viewpoints for perspective
taking, interpolating between observations to reconstruct hidden transitions, continuing observed
dynamics to anticipate future events, or intervening on the scene to reason about intervention
outcomes, as illustrated in Figure 1. A visual reasoner should therefore actively determine what

to imagine according to the reasoning problem and how to exploit the generated visual evidence
to solve it.
To enable task-dependent visual imagination, we introduce CoWorld Reasoner, an agentic
framework that uses a VWM as a unified visual reasoning engine. Unlike an agent confined to
a fixed workflow, it selects among VWM-driven tools to generate unseen views, intermediate
states, continuations, or intervention outcomes according to the question. Skills guide when
to invoke these tools, how to construct requests, and how to interpret the generated video; a
verifier and execution code complete the harness. A predefined harness may fail to elicit the visual
evidence required by different reasoning tasks or to guide its interpretation. Refinement must
coordinate evidence generation and interpretation, because what the VLM can infer depends on
what the VWM can reliably generate. We therefore introduce VLM-VWM Harness Co-Evolution,
which iteratively refines the interface between the VLM and VWM by jointly revising tools, skills,
and execution code based on execution feedback. With both model weights fixed, co-evolution
improves how the two models interact and use task-relevant visual evidence.
We evaluated CoWorld Reasoner on seven benchmarks spanning spatial intelligence [7, 8, 9, 10],
temporal and causal reasoning [11, 12], and perceptual reasoning [13]. Across VLM/VWM
variants, CoWorld Reasoner improves aggregate accuracy over direct reasoning with the same
VLM. The strongest variant (GPT-5.6 and MiniMax H3) improves all seven benchmarks, with
relative gains of 11.8% on MMSI and 13.0% on ERQA. It also outperforms all five evolving baselines
using the same backbone on five benchmarks. Further analysis highlights the contributions of
generated visual evidence and co-evolved control of its request and interpretation.
Our main contributions are summarized below:
1. We leverage a VWM as a unified visual reasoning engine for visual imagination, enabling the
agent to generate task-relevant visual evidence through diverse visual operations.
2. We design a Video World Model-Driven Harness that exposes diverse visual operations through
standardized tools and encodes reusable reasoning workflows as skills, enabling the agent to
decide whether visual imagination is needed, which operation to invoke, and how to interpret
the generated visual evidence.
3. We introduce VLM-VWM Harness Co-Evolution, which iteratively refines the interface between
the VLM and VWM by jointly revising tools, skills, and execution code based on execution
feedback.
4. We evaluate CoWorld Reasoner with multiple VLMs and VWMs across seven benchmarks
spanning spatial intelligence, temporal and causal reasoning, and perceptual reasoning,
showing gains over direct reasoning and strong performance against evolving baselines, while
analyzing the contributions of the harness and its co-evolution.

2.2 World Models
World models capture the structure and dynamics of environments to support prediction and
simulation. Video generation models such as Wan [22], Seedance 2.0 [23], and MiniMax H3 [3]
learn visual dynamics from video data, and Cosmos-Predict2.5 [24] focuses on world simulation.
Marble [25] generates explicit 3D environments that users can explore and edit. Interactive
models such as RTFM [26] generate video in real time in response to user actions. Our approach
treats a VWM as a unified visual reasoning engine and exposes it through multiple VWM-driven
tools.
2.3 Self-Evolving Agents
Recent approaches improve agents by iteratively revising prompts, skills, and code. GEPA
[27] optimizes prompts from execution traces, while SkillOpt [28] refines reusable skills from
execution feedback. DGM [29] revises the agent’s own code, while Meta-Harness [30] optimizes
harness implementations. CoEvoSkills [31] jointly evolves skills and a verifier that guides their
refinement. Our co-evolution supervisor jointly revises the VWM-driven harness to improve both
the generation of visual evidence and the agent’s interpretation of it.

3.2 VLM-VWM Harness Co-Evolution
VLM-VWM Harness Co-Evolution jointly refines the components that govern visual generation and
evidence use, while keeping the VLM and VWM weights fixed. These components are coupled:
changes to request construction can alter the visual cues available in the generated video, which
in turn affect the guidance needed to interpret and integrate them.
Agent execution follows four reasoning stages. At each stage, co-evolution alternates between
forward execution and feedback-guided revision. The agent first runs the current harness on the
development set. A supervisor powered by the same VLM 𝑀uses the resulting feedback to revise
the harness and rerun that stage from the same incoming interaction histories. This cycle can
repeat before the supervisor selects the best candidate and passes its harness and histories to the
next stage. We repeat these four stages for 𝑅evolution rounds.
Progressive execution. During Capability Boundary Assessment (𝑘= 1), the agent judges whether
the VWM can supply useful missing evidence and may load a relevant skill. In Request VWM
Assistance (𝑘= 2), it can revise this assessment before constructing and executing a generation
request or skipping generation. During Video Interpretation (𝑘= 3), it reviews the input images
and interprets any generated video alongside them, optionally requesting verification. Finally, in
Evidence Integration and Reasoning (𝑘= 4), it combines the input images with generated visual
evidence to infer the final answer. The stage and candidate notation below is local to the current

4 Experiments
4.1 Experimental Setup
Benchmarks. We evaluated CoWorld Reasoner on the seven benchmarks in Table 1. MMSI [7]
assesses reasoning about positions and motion across images; SAT [8] covers ego and object
motion, action outcomes, goals, and perspective taking; and Spin [9] tests perspective taking
under translation and rotation. SpatiaLab [10] uses Multiple-Choice (MCQ) and Open-Ended
(Open) questions about real scenes. ERQA [11] combines spatial, physical, and world knowledge,
while CausalSpatial [12] tests reasoning about collisions, occlusions, and trajectories under object
interventions. PerceptionBench [13] covers counting, attributes, and text reading.
Baselines.
We compare with five evolving agents adapted to the same GPT-5.6 inputs and scoring
protocol (HSI, ReasoningBank, Meta-Harness, ExpeL, and GEPA) and use direct GPT-5.6 reasoning
as the reference. The comparison tables also include published results for fine-tuned embodied
models, specialist spatial models, and vision-based agents; mechanisms, configurations, and
source-protocol notes are provided in Appendix A.
Evaluation Protocol. We use 120 development examples, excluded from testing, to evolve
CoWorld Reasoner and the five evolving baselines; 30 examples come from each of MMSI, Spin,
CausalSpatial, and PerceptionBench. Accuracy is 100 × 𝑁correct/𝑁; differences are in percentage
points, and averages are item-weighted. We measure error recovery as accuracy on the subset
of test items that the GPT-5.6 direct reasoning baseline answers incorrectly. Appendix A details
evaluation sizes and scoring protocols.

4.2 Main Results
Overall Performance.
Table 1 shows that CoWorld Reasoner, using its final co-evolved harness,
improves over the GPT-5.6 direct reasoning baseline on all seven benchmarks, especially on MMSI
and ERQA, with gains of 4.54 and 6.75 percentage points, respectively. It leads all five evolving
baselines on five benchmarks and achieves the highest aggregate accuracy. All five evolving
baselines also score below the GPT-5.6 direct reasoning baseline overall. The advantage over
the best evolving baseline reaches 7.07 points on open-ended SpatiaLab. Gains also extend to
SAT, SpatiaLab, and ERQA, which provide no development examples; these results show that the
final harness transfers across benchmarks. Appendix A.6 further compares development and test
performance.
Spatial Intelligence. As shown in Table 2, gains span all four MMSI categories and reach 6.56
points for positional relationships. Overall accuracy approaches SenseNova-SI’s reported result.
SAT perspective taking reaches 84.85%, the highest among the compared methods; goal reasoning
also improves, while object motion declines. Accuracy on Spin likewise improves in the View,
Mental Rotation, and Perspective categories, as detailed in Appendix A.7. The cross-view skill
guides the agent to track object identity and interpret relations in the question’s reference frame.

5 Conclusion and Future Work
We presented CoWorld Reasoner, which treats a VWM as a unified visual reasoning engine through
a Video World Model-Driven Harness of tools, skills, and a verifier. VLM-VWM Harness Co-

CoWorld Reasoner
Evolution uses execution feedback to improve how the agent requests, evaluates, and integrates
visual evidence. CoWorld Reasoner improves over direct reasoning with the same VLM on all seven
benchmarks and outperforms all five evolving baselines on five of these benchmarks. Agentic tool
use and harness co-evolution extend VWM-based reasoning beyond fixed novel-view synthesis
pipelines. Future work will explore test-time training to co-evolve the harness, VLM, and VWM
for visual generation and multimodal reasoning across diverse reasoning tasks.

A.2 Scoring and Usage Statistics
We computed accuracy over all items in each benchmark or category. We normalized multiple-
choice answers before comparing them with the correct option. For PerceptionBench, we used
deterministic option matching when an answer maps to a supplied choice; otherwise, a GPT-5.6
judge evaluates correctness under the benchmark’s general-QA criterion. The same judge evaluates
semantic equivalence for open-ended SpatiaLab questions. The judge operates in an evaluation
context fully independent of the task agent.
Recovery measures accuracy on the subset of test items answered incorrectly by the GPT-5.6
direct reasoning baseline. When combining SpatiaLab MCQ and Open, we aggregated correct
answers and item counts across both formats.
Skill-loading rate is the percentage of items on which the corresponding skill is loaded. Tool-use
rate is the percentage of items with a VWM-driven tool call for the corresponding visual operation.
An item can contribute to multiple columns; the Any column counts items with at least one skill
load or tool call in the corresponding group.
A.3 Agent and Generation Configuration
The task agent, co-evolution supervisor, and external answer scorer each use the gpt-5.6-luna
deployment in separate contexts. The GPT-5.6 direct reasoning baseline answers each item from
the input images in one stage. All five evolving baselines use this GPT-5.6 deployment. Table 5
lists agent and video generation settings.
The agent carries its interaction history through stages 1–4, following the order in Section 3.2.
The verifier receives the generated video. The “Ours (w/o VWM)” variant retains the VWM-driven
skills and four-stage execution while disabling all VWM-driven tools and the verifier.
We used the MiniMax H3 Max Turbo image-to-video endpoint on FAL. A request supplies one
source image or two images defining the start and end frames. Generation requests describe the
visual transformation without prescribing the task answer.
We used 𝑅= 3 evolution rounds. At each stage, the supervisor evaluates the initial candidate
and up to 𝐵= 5 revisions, with early stopping.
For transfer to Grok-4.5, we initialized the harness from the completed GPT-5.6 co-evolution,
replaced the VLM with Grok-4.5, and ran one additional co-evolution round before evaluation.
