## 摘要
文本到视频模型通常能生成自然语言提示所要求的视觉概念，但无法满足其预期的顺序、时序和持续性要求。我们提出将这些要求表示为形式化时序逻辑中的规约，并引入时间规约引导（TSG），一种免训练的推理时框架，将时间规约转化为可执行目标，以在采样过程中引导视频生成。TSG 使用可微定量语义对视觉概念证据的轨迹进行评分，并利用该评分的梯度构建由规约引导的去噪方向。我们以视频-文本注意力轨迹、面向度量时序逻辑的高效可微评分以及由梯度导出的注意力偏置来实例化该框架。该实例化既不需要外部概念分类器，也不需要通过视频 Transformer 进行反向传播。其注意力引导的前向传播产生一个去噪方向，用以增强无分类器引导（CFG）。在涵盖 11 类时间约束（包括有序物体进入和状态转换）的 220 个提示基准上，该实例化在五个模型上将规约满足准确率相较 CFG 提升 9.5–20 个百分点，且内存开销极小。这些结果表明，时间规约与可微满足目标有望作为控制视频生成的灵活接口。

## Abstract
Text-to-video models often generate the visual concepts requested in natural language prompts but fail to satisfy their intended ordering, timing, and persistence requirements. We propose representing these requirements as specifications in a formal Temporal Logic, and introduce Temporal Specification Guidance (TSG), a training-free inference-time framework that turns temporal specifications into executable objectives for guiding video generation during sampling. TSG scores traces of visual concept evidence using differentiable quantitative semantics and uses the score's gradients to construct a specification-guided denoising direction. We instantiate this framework with video-text attention traces, efficient differentiable scores for Metric Temporal Logic, and gradient-derived attention biases. This instantiation requires neither an external concept classifier nor backpropagation through the video transformer. Its attention-steered forward pass yields a denoising direction that augments classifier-free guidance (CFG). On a benchmark of 220 prompts spanning 11 categories of temporal constraints, including ordered object entry and state transitions, this instantiation improves specification satisfaction accuracy over CFG by 9.5-20 percentage points across five models, with minimal memory overhead. These results demonstrate the potential of temporal specifications and differentiable satisfaction objectives as a flexible interface for controlling video generation.

## 2. 方法论

### 2.1 规约语言：MTLf 片段

- 语法：`φ := ⊤ | ⊥ | c | ¬c | φ1∧φ2 | φ1∨φ2 | X_Iφ | φ1 U_I φ2 | G_Iφ`，其中 `c` 为帧级视觉概念（实体存在、实体状态、场景属性），`I ⊆ [0,1]` 为归一化时间区间；`F_Iφ = ⊤ U_I φ` 可导出。
- 区间可表达三种精度：无时序（`[0,1]`）、区间时序（`t1≥0, t2≤1`）、严格时序（`t1 = t2`）；离散化偏移为 `[⌈t1(T−1)⌉, ⌊t2(T−1)⌋]`。
- 示例：`φ_rescue = G[0,1] drone ∧ F[0.5,1](flare_signal ∨ stranded_hiker)`。
- **兼容性**：TempoControl 的二值时间掩码可编码为分段 Always 约束（正文字用 `c`、负文字用 `¬c`）；Choi 等的无时序 TL 规约用平凡区间即可表达。相比掩码，规约可同时接纳多条合法轨迹（含“或”分支）。

### 2.2 TSG 框架（三段式，免训练、推理期）

1. **注意力导出的时间轨迹**：对每个注意力头，把规约中的概念 `c` 映射到提示词 token 集合 `P_c`；对潜帧 `z_t` 的所有空间 query 取“对该概念 token 的最大注意力”并做空间平均，得到原始轨迹 `a_{t,c}`；再用时间维 z-score + sigmoid 校准为概念存在分数 `ŷ(z_t,c) = σ((a_{t,c} − μ_c)/(τ s_c + ε))`。**用视频-文本注意力代替外部分类器**。
2. **可微规约评分（LogSTOP 式 log 域 sum-product）**：合取与 Always 用对数相加（乘积），析取、Eventually、Until 用 logaddexp（求和），Until 按“见证帧 j”展开 `Q_{αU_Iβ}[t] = Σ_j Q_β[j]·Π_{r<t…} Q_α[r]`。借助结合性摘要 `(P,R)∘(P',R') = (PP', R + P R')` 与双栈滑动窗口，在 **O(|φ|·T_z)** 时间内算出所有窗口分数；并证明分数对独立文字支撑单调（Prop B.3），从而在极性一致时梯度符号可预测（Cor B.4）。
3. **在线注意力引导**：对原始轨迹求梯度 `g = ∇_a ŷ(z,φ)`，按无穷范数归一化并乘步长 `η`，广播到该概念对应的“时间位置 × 文本 token”注意力 logit，跨文本 key 去均值后裁剪到 `[−1,1]`，逐层逐头在线注入 `L̃ = L + B`。**只在 detach 的轨迹与分数上反传，不反传视频 Transformer**。

### 2.3 与 CFG 的融合

- 额外一次带引导的条件前向得到 `d_{k,φ}`，最终方向：
  `d_{k,tsg} = d_{k,cfg} + λ_{k,tsg}(d_{k,φ} − d_{k,c})`
- 强度用**范数配比**自适应设定：`λ_{k,tsg} = ρ_{k,tsg} · ‖λ_{k,cfg}(d_{k,c} − d_{k,u})‖₂ / ‖d_{k,φ} − d_{k,c}‖₂`，默认 `ρ = 1`（与 CFG 贡献等量级）。
- 仅在**前 15 个去噪步**施加 TSG，其余步保持 CFG；实测 `ρ=1` 最优，`ρ` 增大反而退化。

  - 引导组合消融：25 提示 × 2 模型 × 4 种配置；

- **充分之处**：覆盖两个模型家族、两种注意力架构、五个规模档位；同时评测“区间时序”与“严格时序”两类基准；报告准确率 + 质量 + 延迟 + 显存四维代价；成对潜变量重放使对比较严格；附录给出完整提示模板、超参、评测 prompt 与不确定标签敏感性分析（0.94% “unclear”，保守处理不改变结论）。
- **不够充分之处**：每条提示仅生成 1 段视频（单种子），未报告跨种子方差；无人类主观评测，规约满足度完全依赖单一 VLM 判定器；图像质量仅用 MUSIQ 一项，未评运动一致性/文本对齐；超参（η、裁剪区间、引导层数、τ）未做系统扫描；TempoControl 的复现属“移植”，与原实现可能存在细节差异。

## 6. 主要结论与发现

- **有效性**：主基准上 TSG 相对 CFG 提升 **9.5–20 个百分点**（CogVideoX-2B +20.0、CogVideoX-5B +18.2、Wan2.1-1.3B +15.5、Wan2.2-5B +9.5、Wan2.2-A14B +10.9）；最高绝对准确率为 A14B 的 46.8%。
- **小模型 + TSG ≈ 大模型**：Wan2.1-1.3B 加 TSG（31.4%）优于 Wan2.2-5B 仅用 CFG（25.0%）。
- **严格时序任务**：单物体 87.02%（超 CFG +17.6pp，超完整 TempoControl +2.97pp）；双物体 58.07%（+22.0pp，+0.58pp）；同时峰值显存仅为 TempoControl 的约 38%（约低 62%），延迟约为其 1/3–1/2。
- **代价**：显存几乎无额外开销；延迟上升 1.45×–3.49×；图像质量最多降 3.0 分，A14B 反升 3.2 分。
- **类别差异**：收益最大的是备选终态（23%→66%）、两态转换（35%→71%）、可逆状态回归（21%→43%）；重叠交接（~9%）、触发响应（~17%）、三实体有序进入（~12%）仍困难，增益仅约 2pp——说明“多实体出现/消失/依赖协调”仍是瓶颈。
- **设计验证**：`ρ=1` 最优，`ρ≥2` 递减，`ρ=5` 回落至 CFG 水平；CFG+TSG 优于 CFG×2、TSG-only 及 TSG→CFG 混合，证明增益不是“单纯加大引导强度”的假象。

## 7. 优点

- **问题建模优雅**：把模糊的自然语言时间要求提升为可判定、可微、可复用的形式化规约，且能**统一表达**已有工作的时间掩码与无时序 TL，表达力更强（支持“或”分支、多条合法轨迹）。
- **真正的免训练、低显存**：只在 detach 的注意力轨迹上求梯度，不反传视频 Transformer、不需外部分类器，因此显存与 CFG 几乎相同，工程落地成本低。
- **算法效率有理论保障**：log 域结合性摘要 + 双栈滑动窗口实现 O(|φ|T_z) 评分，并给出单调性、梯度符号、正确性与复杂度证明，方法不是纯启发式。
- **引导强度自适应**：用范数配比定义 λ_tsg，避免不同模型/步数下需要重新调引导尺度。
