## 摘要
人类随着问题的展开，灵活组合不同形式的推理来对物理世界进行推理。实现这种灵活性是 AI 的一项重大开放挑战：各项能力往往分散在专门模型中，限制了它们如何被组合并联合适应于一项任务。我们提出 $Ψ$-0.6，一个统一的视觉-语言世界模型，它在一种我们称为“思维流”的共享推理过程中自适应地组合感知、语言、几何与仿真。这些思维流交替包含图像、文本以及几何与运动的显式表示，模型可以通过共享的 token 接口生成并解释所有这些内容。$Ψ$-0.6 在多视图空间推理上零样本超越领先的开放权重模型，并且通过几何中间表示进行推理还能获得进一步提升。它还支持反事实仿真：生成并解释想象场景，以判断例如移动一个物体是否会阻碍通路。来自任务反馈的强化学习联合优化中间表示的选择、生成与使用，提高视觉问答准确率，且增益可迁移到未见基准。$Ψ$-0.6 为自适应物理推理提供了一条路径——不仅预测物理世界，还选择用于推理的表示。

## Abstract
Humans reason about the physical world by flexibly combining different forms of inference as a problem unfolds. Achieving this flexibility is a major open challenge in AI: capabilities often remain separated across specialized models, limiting how they can be composed and jointly adapted to a task. We introduce $Ψ$-0.6, a unified vision-language world model that adaptively composes perception, language, geometry, and simulation within a shared reasoning process we call streams of thought. These streams interleave images, text, and explicit representations of geometry and motion, all of which the model can generate and interpret through a shared token interface. $Ψ$-0.6 surpasses leading open-weight models zero-shot on multi-view spatial reasoning, with further gains from reasoning through geometric intermediates. It also supports counterfactual simulation: generating and interpreting imagined scenes to determine, for example, whether moving an object would obstruct a pathway. Reinforcement learning from task feedback jointly optimizes the selection, generation, and use of intermediate representations, improving visual question-answering accuracy with gains that transfer to unseen benchmarks. $Ψ$-0.6 offers a path toward adaptive physical reasoning -- not only predicting the physical world but also choosing the representations through which to reason.

## 二、方法论

### 2.1 核心思想：思维流（Streams of Thought）

- 将**图像、文本、相机位姿、深度、光流、点轨迹**全部序列化为离散 token，由同一个 8B 参数自回归 transformer 处理；感知、描述、仿真都变成不同的条件预测。
- 推理过程是交错这些表征的序列，模型既能**生成**也能**解读**它们，输出可作为下一步的上下文。

### 2.2 通用提示接口（Any-to-any Prompting）

- 所有任务都表达为 **token 排序**：提示指定"给定什么"与"请求什么"，不同组合对应不同推理路径。
- 示例：`RGB0, C0→1 → RGB1` 为新视角合成；`RGB0, RGB1 → C0→1` 为位姿估计；把 C 换成 F 即运动条件生成 / 光流估计。同一相机位姿既可作估计结果、也可作生成命令、还可作推理中间量。
- **组合推理**：一个预测的输出成为下一个预测的上下文（如先生成目标视角图像，再据此回答空间问题）。
- **细粒度控制**：每个 patch 由 1 个指针 token（ID 65,000，编码模态与时空位置）+ 内容 token 组成，内容与位置分离，支持局部条件化与场景编辑。
- **概率预测**：对部分指定场景建模兼容延续的分布，同一提示可采样出多种合理预测。

### 2.3 训练配方（三阶段）

- **预训练**：大规模视频上先做 RGB 与相机条件预测，再逐步加入深度、光流，学习外观—几何—运动的联合关系（继承 PSI/Ψ 框架）。
- **中期训练**：先用 FineWeb-Edu、DCLM 纯文本学语言，再加入图文/视频—字幕做视觉语言对齐（全局与时间索引字幕）。
- **后训练**：指令微调（图像/视频问答、相机与物体运动的文本控制）、空间推理、反事实想象；并保留前两阶段数据以维持广泛预测能力。

### 2.4 关键技术细节

- **架构**：32 层、隐藏宽度 4096、32 查询头 / 8 KV 头、头维度 128、SwiGLU 宽度 16384、词表 65536、通道嵌入 384、基础序列长度 4096；三轴 RoPE（x/y/t = 48/48/32）。
- **视觉量化**：16×16 patch 经 Haar 小波 + 残差块编码，FSQ（8,8,8,5,5,5）得 64,000 索引；RGB 每 patch 4 码，深度/光流 2 码；量化器独立训练并冻结。
- **相机位姿**：相对位姿离散为 8 个整数（2 个视场角 + 3 轴角 + 3 平移）。
- **pMotion 解码**：先用一次前向估计每个 patch 的运动概率，按概率从高到低依次生成光流，把序列预算集中在可能运动的区域。
- **CFG 引导**：`z_guided = z_ref + s(z_cond − z_ref)`，放大文本指令对运动的影响。

### 2.5 强化学习：自适应思维流

- 把"选择哪种中间表征"变成策略动作：给定视频 v 与问题 q，策略输出记号 z（如 `d0, c2→3, f2→3` 表示第 0 帧深度、第 2→3 帧相机运动与光流）。
- **两阶段训练**：
  1. 用当前策略采样记号，以"相对 RGB-only 的答案损失下降"打分，做过滤式行为克隆（拒绝采样微调）；
  2. 用 **Dr. GRPO** 在线优化 LoRA 参数，奖励 `r(a) = ℓ(∅) − ℓ(a)`，组内相对优势 `A_i = r_i − mean(r)`，并加 KL 正则约束回初始策略。
- 因中间表征由推理器自身生成（而非外部工具），其**选择与内容可端到端联合优化**，支持共适应、反事实/未来状态生成、任务相关表征。

## 六、主要结论与发现

- **统一带来三重收益**：强零样本能力、组合式物理推理、可从任务反馈学习自适应推理策略。
- **MindCube**：零样本 49.7–51.3%，优于开放权重通用 VLM 与空间专家模型；组合提示（逆动力学）达 **57.7%**；SFT 后 RGB-only 68.7%、RGB+C **76.3%**，超过 SFT 版 Qwen2.5-VL 与 3DThinker-SFT，接近 3DThinker SFT+RL，仍落后 GeoThinker（83.0%）。
- **FlowBench 流预测**：最佳配置 Acc **56.4%**、rEPEmove **0.454**，显著优于最强图像编辑基线（16.4% / 2.655）与 FOFPred（0.915），甚至超过使用 oracle 输入的模块化专家流水线（50.8% / 0.552）；且所有 Ψ-0.

…变体在流预测任务上均优于所有基线，说明"统一预测器 + 联合优化"相对"模块化专家流水线"具有结构性优势，而非单点调参的结果。

- **流预测消融的关键发现**：
  - **pMotion 解码**是精度与效率的共同来源——按运动概率排序生成光流，把有限的序列预算集中到真正运动的区域，避免了稠密均匀解码在静态背景上的浪费；
  - **CFG 尺度**存在明显的工作区间：过小则文本指令对运动的调制不足，过大则牺牲外观合理性，需在"指令遵循"与"画面保真"之间取舍；
  - **序列长度**直接决定可表达的运动复杂度，长度不足时快速/大幅度运动会退化为模糊或错误的流场。
- **FlowBench-Sim VQA**：模型在需要"想象物体被移动后场景如何变化"的问题上明显优于通用 VLM 与仅靠文本 CoT 的推理方式，说明**生成式仿真作为推理中间步骤**确实提供了语言无法替代的空间-物理信息；分类别看，涉及方向、碰撞/遮挡与多步运动的题目提升更显著，纯语义或常识类题目优势较小。
- **FlowBench-Real 迁移**：训练完全未接触这五个机器人数据集，仍有正向迁移，表明学到的不是数据集特定的外观先验，而是较通用的"运动—几何—接触"关系；但真实场景的绝对准确率低于仿真，域差距（相机标定、噪声、非刚性物体）仍是瓶颈。
- **RL 自适应思维流**：
  - 在 4 个训练分布 held-out 集上，学习到的记号选择策略优于固定使用 RGB、固定使用 RGB+D 等手工配置，说明"选哪种表征"确实是可学习的、任务相关的；
  - 在 4 个**完全未见**的基准（HanDyVQA、TGIF-QA、STAR、EgoPlan-Bench2）上同样取得提升，提示策略学到的是"何时需要几何/运动信息"的一般性判断，而非对训练任务记忆；
  - **损失下降分析**显示：中间表征带来的收益与问题类型强相关——需要精确空间/运动判断的题目收益大，纯语义题目收益接近零甚至为负，这解释了为何自适应选择优于"总是生成更多表征"；
  - **best-of-16 上界**明显高于单次采样，说明当前策略的记号选择仍有较大提升空间，主要误差来自"选错表征"而非"用错表征"。
- **总体结论**：论文验证了一条可行路径——把感知、描述、仿真统一为同一 token 空间中的条件预测，并让"推理媒介的选择"成为可端到端优化的策略，从而同时获得零样本泛化、组合式推理与任务自适应三方面能力。

## 七、局限与批判性评估

**作者自述的局限**：

- 模型规模（8B）与数据/算力投入远小于当代前沿多模态系统，绝对性能仍有差距（如 MindCube 上落后 GeoThinker 约 6–7 个百分点）；
- 真实场景的流预测与反事实推理受域差距限制；
- RL 阶段的策略空间是离散的"记号组合"，尚未扩展到连续或更长程的推理规划。

**分析者补充的判断**：

- **公平性**：作者主动披露图像编辑基线获得 GT frame-0 mask 的 oracle 优势，并指出这反而低估了 Ψ 系列，态度值得肯定；但 SFT 组的训练数据量、超参并未与所有对比模型完全对齐，跨模型比较应谨慎解读。
- **评测范围**：Benchmark 集中于室内桌面上物体与相机运动，缺乏流体、形变、多物体接触等更复杂物理过程；"物理推理"的覆盖面仍偏窄。
- **因果归因不足**：论文展示了统一带来的收益，但未做**隔离实验**（例如固定参数量下分别去掉深度/光流通道、去掉联合训练）来量化每一路表征与联合优化的独立贡献，"统一"与"规模/数据"的贡献边界尚不清晰。
- **RL 奖励设计**：奖励定义为"相对 RGB-only 的答案损失下降"，依赖一个可靠的损失度量与可比的答案空间；对开放式生成任务如何推广未讨论，且 KL 约束下的策略可能偏向保守的记号选择。
- **可复现性**：量化器、三轴 RoPE、pMotion 等细节描述充分，但训练数据配比、RL 采样预算、上下文扩展的具体配置披露有限，完整复现难度较高。
- **效率**：以 token 序列承载图像/深度/光流，长序列成本高；论文虽用 pMotion 缓解，但相对专用编码器在推理延迟上的劣势未系统评估。

## 八、学术定位与启发

- **定位**：论文处于"统一多模态模型"与"世界模型/物理推理"两条脉络的交汇处，其真正新颖点不在"多模态共享骨干"（已有大量工作），而在**把推理媒介的选择建模为可学习策略**，并用 RL 让生成器与推理器共适应——这区别于把工具当黑盒的工具增强型 VLM。
- **方法论启发**：
  - "任何任务都是 token 排序问题"的 any-to-any 提示接口，是一种优雅的任务统一方式，便于把新模态以最小改动接入；
  - "指针 token + 内容 token"的位置/内容分离设计，为细粒度局部条件化与场景编辑提供了通用机制；
  - 以"答案损失下降"作为中间表征的效用信号，是一种无需人工标注推理轨迹的弱监督 RL 范式，可迁移到其他"选择工具/选择视角"的场景。
- **对后续研究的建议方向**：引入更强的物理约束或仿真器作为验证信号；把策略空间从离散记号扩展到分层/长程规划；在更大规模与更多模态（力、触觉、音频）上检验统一范式的可扩展性；系统评估推理时延与 token 效率的权衡。

## 九、一句话总结

论文提出以"思维流"统一图像、文本、相机位姿、深度、光流与点轨迹的表征与预测，并用强化学习让模型自主选择推理媒介，在空间推理、反事实运动问答与跨域迁移上验证了"统一 + 自适应"路线的可行性与潜力，同时在规模、评测覆盖与因果归因上留有明显空间。
