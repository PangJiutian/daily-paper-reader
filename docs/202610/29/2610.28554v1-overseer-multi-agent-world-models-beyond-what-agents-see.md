## 摘要
尽管视频世界模型取得了成功，将其扩展到多智能体仍然困难，因为这需要生成多个面向各智能体的视频流，且这些视频流在时间上以及智能体之间保持一致。为弥补这一空白，我们提出 OverSeer，一种多智能体世界模型，它用辅助相机视角增强以自我为中心的智能体视角。我们认为，通过在空间上固定辅助视角，它们可作为以世界为中心表示的代理：与智能体视角不同（智能体位置的简单变化即可使其完全改变），辅助视角的变化直接映射为世界状态的局部变化。我们表明，这些固定视角能显著帮助模型保持一致性。我们还表明，由于其冗余且半静态的性质，辅助视角可通过 delta-VAE 高效压缩，该 VAE 仅编码相对于静态参考图像的变化，从而减少处理这些视角所需的 token 数量。在 Minecraft 和 Doom 中的实验表明，世界与智能体一致性得到提升；真实世界多相机采集的定性结果表明，该方法并不局限于游戏引擎。我们的压缩分析进一步表明，delta-VAE 大幅降低了辅助视角生成的计算开销。我们得出结论：这些固定视角为改进多智能体世界模型提供了一种简单而高效的方式。

## Abstract
Despite the success of video world models, extending them to multiple agents is difficult because it requires generating several agent-specific video streams that are consistent in time and between agents. To address this gap, we introduce OverSeer, a multi-agent world model that augments egocentric agent views with auxiliary camera views. We suggest that, by fixing the auxiliary views in space, they act as a proxy for a world-centric representation: Unlike the agents' views, which can change entirely due to a simple change in agent position, changes in the auxiliary views directly map to localized changes in the world state. We show that these fixed views substantially help the model to maintain consistency. We also show that, due to their redundant and semi-static nature, the auxiliary views can be efficiently compressed with a delta-VAE that encodes only the changes relative to a static reference image, reducing the number of tokens required to process them. Experiments in Minecraft and Doom demonstrate improved world and agent consistency, with qualitative results on real-world multi-camera captures indicating that the approach is not tied to game engines. Our compression analysis further shows that delta-VAE substantially reduces the computational overhead of auxiliary-view generation. We conclude that these fixed views provide a simple and efficient way to improve multi-agent world models.

## 1. 核心问题与研究动机

- **背景**：视频世界模型（video world model）把环境演化建模为「以动作条件驱动的视频扩散」，从单智能体自视角（egocentric）预测未来帧。近年在高保真度与角色可控性上进展显著，但长时程一致性仍脆弱——小误差累积会导致物体漂移、场景不一致。
- **多智能体的额外困难**：需要同时生成多个智能体各自的视频流，且这些流必须（i）在时间上一致，（ii）在智能体之间一致。作者将其拆为两类一致性：
  - **世界一致性（world consistency）**：场景元素与历史事件效果需持久保留，智能体重访某地时场景应反映其历史。
  - **智能体一致性（agent consistency）**：同一交互在所有可见视角中应被一致地描绘。
- **根本症结**：仅用玩家中心流时，每个玩家的观测都是对底层世界的**局部、随位姿剧烈变化**的投影；将联合分布分解为独立单智能体模型 ∏ᵢ p(z^{A,i}_{t+1} | s^i_t, a^i_t) 无法强制重叠区域一致，也无法保证「一个智能体看过的区域」在另一智能体后来观察时保持一致。
- **理想方案与其代价**：显式维护**世界中心（world-centric）表示**可解决上述问题，且更高效（只有真实变化才产生局部更新，而相机自运动会让完全静态的场景也产生剧烈像素变化）；但从局部观测重建并维护全局状态非常困难。
- **本文主张**：不做显式全局状态重建，而是用**空间固定的辅助相机视角**作为世界中心表示的「实用代理（proxy）」。其三个好处：
  1. 覆盖单个智能体视野之外区域，为跨智能体交互提供共享视觉参照；
  2. 相机静止 ⇒ 其视角的时间变化直接对应真实环境变化，而非自运动；
  3. 固定视角使时间冗余可预测、易建模，强化跨流结构连贯性。
- **配套问题**：辅助视角冗余且半静态，若按普通视频流建模，开销与智能体流相当。为此提出 **δ-VAE**，只编码相对静态参考帧的变化。

## 2. 方法论

### 2.1 问题形式化

- 单智能体：p(z_{t+1} | s_t, a_t)，z_t = E(o_t)。
- 多智能体：p(z^A_{t+1} | s_t, a_t)，z^A_t = {z^{A,i}_t}，a_t = {a^i_t}；s_t 为共享世界状态，须从局部且随运动变化的 z^A_{≤t} 推断。
- 引入 K 个固定位姿辅助相机 o^X_t = {o^{X,j}_t}，位姿 c = {c^j}。
- OverSeer 的联合生成目标：

  p( z^A_{1:T}, z^X_0, d^X_{1:Q} | z^A_0, a_{0:T−1}, c )

  即同时预测：未来智能体隐变量、辅助视角**首帧锚点** z^X_0、以及压缩后的辅助动态**残差码** d^X_{1:Q}。辅助图像仅在训练时需要。

### 2.2 模型架构与条件注入

- 基座：**Wan2.2-TI2V-5B** 潜空间视频扩散模型（DiT），沿用其预训练视频 VAE 与生成先验。
- **动作条件**：离散动作（前后左右、跳跃、攻击、鼠标转向等，共 28 类）转写为英文短句 → 冻结 **T5** 文本编码器 → 通过 **cross-attention** 注入 DiT。
- **相机条件**：辅助相机的位姿 c^j 与内参转为 **Plücker 射线图**，patchify 后经 **AdaLN**（scale/shift）调制对应辅助 token。
- **统一注意力**：所有智能体流与辅助流的 token 投影到同一 DiT 隐维度，加**视角标识嵌入（view-identification embedding）**，由**共享 self-attention** 联合处理，实现跨模态直接通信。
- **因果时间掩码**：位置 t 的 token 只能关注条件 token 与 t′ ≤ t 的 token，防止未来信息泄漏（配合 diffusion forcing 的独立时间步采样）。
- **训练**：diffusion forcing，初始条件帧 z^A_0 保持干净；辅助锚点帧与残差码与未来智能体隐变量一同作为扩散目标。

### 2.3 δ-VAE：辅助动态的高效建模

- **动机**：固定相机的背景几乎静止，逐帧建模完整 latent 存在严重时空冗余。
- **锚点 + 残差码**：保留首帧 latent z^{X,j}_0 ∈ R^{H×W×C} 作静态锚点；后续序列切为 Q 个不重叠块（块长 τ）。每块编码为 d^{X,j}_q ∈ R^{H/s × W/s × C_d}，得到 **s² 空间 × τ 时间**的 token 缩减。默认 s=2、τ=2，即 **8× 压缩**：576×384 下从 864 token/帧降到 108 token/帧。
- **结构**：编码器用时空 Transformer 联合处理锚点与目标块，参数化高斯分布并采样残差码；解码器把锚点按 τ 个时间位置复制（加可学习时间位置嵌入），通过 cross-attention 读取残差码，重建目标 latent。
- **三项目标**：
  - L_rec：重建 latent 的 ℓ1 损失；
  - L_KL：标准 VAE KL 正则；
  - L_align：受 REPA 启发的特征对齐损失。先由通道级 latent 距离构造变化权重图
    M^{X,j}_t = ‖z^{X,j}_t − z^{X,j}_0‖_{2,C} 归一化，
    再加权特征 r^{X,j}_t = M^{X,j}_t ⊙ z^{X,j}_t，在 τ×s×s 块上池化，用线性投影 P 把 d^{X,j}_q 对齐到该池化特征。
  - 总损失 L = λ_rec L_rec + λ_KL L_KL + λ_align L_align，权重 1 / 1e−5 / 1e−3。
  - 关键设计考量：**只用 latent 距离定位动态区域，对齐目标仍由目标 VAE 特征本身构造**，避免非线性潜空间中的朴素相减产生无意义表示。
- **训练流程**：先单独训练 δ-VAE 并冻结，再训练世界模型 OverSeer。
