ABSTRACT
Interactive video world models aim to follow user actions while maintaining scene
consistency over extended interactions. History-based methods reuse generated
latents to preserve scene content, but three limitations of this reuse contribute
to error recirculation. 1) The latent generated at each interaction is retained as
history, potentially containing blurred details, geometric distortions, or semantic
drift. 2) Although retrieved historical content matches the current scene, it can
still contain errors that are carried into the next chunk. 3) New outputs then be-
come history for later interactions, potentially reinforcing the same errors through
repeated reuse. To limit this cycle, we aim to predict the future scene state from
the current generated latent and the next action before generating the next interac-
tion’s video chunk. This future-state prior provides guidance for the next chunk,
with the aim of reducing the errors carried forward from history. To this end,
we propose a plug-and-play Causal Next-Chunk Predictor (C-NCP) with cross-
model adaptability and prediction-guided modulation. We integrate C-NCP into
four base generators and evaluate the augmented models across three benchmarks

INTRODUCTION
Interactive video world models (Li et al., 2025a; Sun et al., 2025; Team et al., 2026c; Wu et al.,
2026a; Wang et al., 2026; Zhu et al., 2026; Zhao et al., 2026c; Team et al., 2026b;a; Chen et al.,
2026; Zhao et al., 2026a; Ji et al., 2025) generate visual environments that evolve under user action
control. Sustained interaction requires each new chunk to follow the next action while preserving
the scene’s structure and semantics. As interactions continue, local generation defects can affect
subsequent chunks, making error propagation a central obstacle to long-horizon consistency.
To maintain scene consistency, history-based approaches (Sun et al., 2025; Wang et al., 2026; Li
et al., 2025b; Zhu et al., 2025; Yu et al., 2025a; Zhao et al., 2026d; Yu et al., 2025b; Kim et al.,
2026; Yin et al., 2026) repeatedly retrieve and reuse generated content. However, this reuse can
lead to error recirculation. Defects from earlier generations enter new outputs, which are then
added to history and reused in later interactions, as illustrated in fig. 1. Three limitations of history
reuse contribute to this cycle. First, the latent generated at each interaction is retained as history,
potentially containing visual defects such as blurred details, geometric distortions, or semantic drift.
Second, although a retrieved history view matches the current scene, it can still contain errors.
Reusing such a view can therefore propagate these errors to the next chunk. Third, the new output
is then added to history and reused in later interactions, potentially reinforcing the same errors. To
limit this cycle, the generator needs guidance for the next chunk that does not rely solely on reusing
potentially flawed history.
Based on this analysis, our motivation is to predict the future state from the current generated latent
and the next action, providing an explicit future-state prior before generating the video chunk for the
next interaction. Supervision from real video transitions teaches the predictor how scenes change
under action control. It uses these learned transitions to re-estimate the upcoming state, rather than
only selecting content already present in history. The resulting future-state prior guides the next
generation, with the aim of reducing errors carried forward from earlier outputs. To turn this prior
into effective guidance, we need to meet the following two requirements. (1) Adaptability. To
make future-state prediction usable across different interactive video generators, the predictor must
adapt to their latent representations. Different models use VAE latents with different dimensions and
distributions, so the predictor needs a way to accommodate these differences. (2) Modulation. The
future-state prior must also help guide the generation of the next chunk. Direct concatenation places
the predicted latent alongside the generator’s main latent, but the generator must still learn how to
use this extra input when producing the next chunk. Modulation instead uses the future-state prior
to adjust the main latent directly, while keeping its tensor shape unchanged. These considerations
lead to our central research question.
How can we predict a future state from the current generated latent and the next action, and
use it to guide subsequent generation and limit error propagation across interactions?
To address this question, we propose the plug-and-play Causal Next-Chunk Predictor (C-NCP),
which estimates the complete next latent chunk from the current interaction’s generated latent and
the next interaction’s action control. We use Bayesian decision theory (S¨arkk¨a & Svensson, 2023)
to formulate this prediction task as learning a future-state estimate that minimizes expected predic-
tion loss given the current latent and next action. To enable adaptation, VAE-specific input adapters
map each model’s latents into a shared representation for the causal spatiotemporal predictor, while
output heads map its predictions back to the corresponding model’s latent space. To enable mod-
ulation, we use the future-state prior to adjust the generator’s main latent through residual feature
modulation based on adaptive instance normalization (Huang & Belongie, 2017). After each inter-
action, the newly generated latent becomes the input to the next prediction, so the future-state prior
is updated as interaction continues. Our main contributions are summarized as follows.

learns to re-estimate the state expected under the next action. The resulting prior guides
each new chunk before it becomes part of history.
• We develop the plug-and-play Causal Next-Chunk Predictor with cross-model adaptability

RELATED WORK
Interactive Video World Models. Interactive video world models (Li et al., 2025a; Sun et al.,
2025; Team et al., 2026c; Wu et al., 2026a; Wang et al., 2026; Zhu et al., 2026; Zhao et al., 2026c;
Team et al., 2026b;a; Chen et al., 2026) extend visual generation to environments that evolve under
action control. Early token-based systems such as iVideoGPT (Wu et al., 2024) model observations,
actions, and rewards within an autoregressive sequence. Matrix-Game 2.0 (He et al., 2025) and
LingBot-World (Team et al., 2026c) develop real-time streaming generation across diverse environ-
ments, while SANA-WM (Zhu et al., 2026) combines hybrid linear attention and long-video refine-
ment for efficient minute-scale generation. Recent work also addresses the mismatch between clean
training contexts and generated histories. Matrix-Game 3.0 (Wang et al., 2026) reuses prediction
errors to expose the model to imperfect conditioning, and DreamX-World (Team et al., 2026b) com-
bines residual recycling with training on self-generated long-horizon contexts. These approaches
improve the generator’s ability to continue from its own outputs rather than assuming error-free
history. However, remaining defects in generated history can still affect subsequent chunks. Our
plug-and-play Causal Next-Chunk Predictor provides an explicit future-state prior before the next in-
teraction’s video chunk is generated. It learns from real video transitions, and VAE-specific adapters
accommodate different latent representations so that the predictor can be integrated into different
base generators.
History Modeling for Video Generation. History modeling preserves scene context through re-
trieval and compact memory. Spatial-memory world models (Wu et al., 2026b) reconstruct static
3D scenes for rendering along target trajectories, while WorldPlay (Sun et al., 2025) reconstructs
relevant historical context. WorldKV (Yi et al., 2026) retrieves viewpoint-matched chunks and com-
presses redundant tokens; Matrix-Game 3.5 (Qian et al., 2026) uses geometry-aware patch memory;
and ReWorld (Chen et al., 2026) combines a bounded KV cache with a pose-indexed landmark bank.
Compression and adaptive selection further reduce context costs. FramePack (Zhang et al., 2026)
uses frame-dependent compression and anti-drifting sampling, while TinyHistory (Zhang et al.,
2025) learns compact history embeddings through frame-query pretraining and content-consistency
learning. Infinite-World (Wu et al., 2026a) uses pose-free hierarchical memory, and CaR (Peng et al.,
2026) combines context compression with attention-based implicit retrieval. OmniMem (Zhao et al.,
2026b) sparsely retrieves KV blocks from historical caches. Future Forcing (Luo et al., 2026) uses
future-query proxies to guide KV retention and merging. Retrieval and compression help preserve
scene content, but the generated latents they reuse can still contain visual defects. When these
defects enter new outputs and those outputs become history, repeated reuse can cause error recircu-
lation. To address this problem, our predictor learns how scenes change under action control from
real video transitions and predicts the next latent state from the current generated latent and the
next action. The resulting future-state prior guides the generator’s main latent through modulation,
aiming to reduce the errors passed into subsequent chunks.

4.2
IMPLEMENTATION DETAILS
Each training sequence contains 1800 frames divided into 60-frame chunks. We train the predictor
on eight A100 GPUs following the two-stage schedule in section 3.3, with 100k iterations per stage.
The predictor and its adapters are optimized using AdamW with a learning rate of 10−4. The nor-
malized loss uses λ1 = 1, λ2 = 1, and λtemp = 0.25. The VAEs and base generators remain frozen.
Architecture and additional optimization settings are provided in Appendices A.2 and A.3. We use
four base generators: Matrix-Game 3.0 (Wang et al., 2026), HY-World 1.5 (Tencent Hunyuan, 2025),
LingBot-World-Fast (Team et al., 2026c), and SANA-WM (Zhu et al., 2026).
4.3
QUANTITATIVE COMPARISON
We compare all four base generators with their predictor-augmented counterparts and include other
interactive video world models as external references. Sekai-val and WBench results are provided in
Appendices B and C. On RealEstate10K-test as shown in table 1, every predictor-augmented gener-
ator improved across all reported metrics. Subject and background consistency increased alongside
temporal and visual-quality scores, with Matrix-Game 3.0 + Ours achieving the highest average.
The improvements across all four bases indicate that the benefit is not confined to a single gener-
ator. Since the predictor was trained on Sekai, these results also support cross-dataset transfer of
the learned transition prior. The gains are consistent with explicit future-state prediction providing
a useful reference for maintaining scene continuity under action-driven viewpoint changes.
4.4
QUALITATIVE COMPARISON
Figure 3 compares four base models with and without our predictor across the sampled 60-second
rollouts. For Matrix-Game 3.0, our predictor better preserved the prominent painting and gallery
layout, which changed in the baseline. For HY-World 1.5, it maintained the red car and garage
structure, while the baseline drifted toward a different vehicle-filled setting. For LingBot-World-
Fast, it retained vehicle appearance and road layout, whereas later baseline frames showed vehicle
distortion and disrupted road content. For SANA-WM, it preserved clearer elephant head and ear
contours than the baseline in later frames. These examples illustrate improved subject and scene
consistency during continued interaction, in recognizable object details and the surrounding scene
layout. Each forecast uses the current generated latent and the next action, so the reference follows
the ongoing interaction. The reduced drift is consistent with this supervised future-state reference
guiding each new chunk through modulation, helping refine generation beyond the reuse of poten-
tially imperfect history. User-study results are provided in Appendix F.

CONCLUSION
We presented the Causal Next-Chunk Predictor, a plug-and-play module that guides interactive
video generation through explicit future-state prediction. Trained through direct supervision from
real video transitions, it estimates the next latent chunk from the current interaction’s generated latent
and the next action control. Feature modulation incorporates this learned reference into the genera-
tor’s main latent to refine each new chunk before it becomes part of the history. Experiments with
four base generators on Sekai-val, RealEstate10K-test, and WBench show consistent improvements
in visual quality and long-horizon consistency over the corresponding baselines. These findings
support future-state prediction as an effective guide for more coherent generation in existing world
models during sustained interaction.

A.1
CONDITIONAL-MEAN INTERPRETATION
The squared-error interpretation in eqs. (4) and (5) separates uncertainty in the future state from
error in its estimate. For finite-second-moment Y and a square-integrable predictor f(C), write
Y −f(C) = (Y −m(C)) + (m(C) −f(C)). The cross term vanishes by conditional expectation
E⟨Y −m(C), m(C) −f(C)⟩F
= E⟨E[Y −m(C) | C], m(C) −f(C)⟩F = 0,
where ⟨·, ·⟩F is the Frobenius inner product over latent entries and m(C) = E[Y | C]. Expand-
ing the squared norm then gives eq. (5). The first term measures uncertainty remaining under the
available context; the second measures deviation from its conditional mean. This motivates learning
a future-state reference from real transitions, but does not establish error contraction on generated
inputs. The normalized mixed objective in eq. (11), which also includes absolute-error and tempo-
ral terms, need not share the conditional-mean optimum. Finite-capacity training and differences
between training and generated contexts further limit this idealized interpretation.
A.2
PREDICTOR ARCHITECTURE
The predictor supports three VAE latent domains with 16, 48, and 128 channels through domain-
specific 1 × 1 × 1 input adapters and output heads, together with action-control adapters. The
VAE-specific input maps in eq. (6) are trained jointly with the predictor to accommodate channel-
count, scale, and channel-statistic differences before the shared trunk. They preserve each domain’s
temporal/spatial grid rather than requiring identical grids across VAEs. The future-query stream
starts with a learned token and encodes preceding ground-truth slices during training or preceding
predictions during forecasting. Together with the mask in eq. (7), this shift prevents access to the
current target or later targets.
Each block applies Causal Temporal Attention and a feed-forward network (FFN), followed by
Dense Spatial Attention and an FFN over each slice’s full spatial grid. These sublayers use pre-
normalization, residual connections, and positional embeddings. The trunk has four blocks, hidden
width 768, 12 attention heads, an FFN expansion ratio of four, and no dropout. Domain-specific
output heads map the future-query features in eq. (8) back to native VAE channels. The model
predicts the full future latent directly; additive feedback in eq. (9) modifies inputs, not outputs.

USER STUDY
We conducted a paired user study with 100 participants, each evaluating all 20 video pairs, with five
pairs per base generator. The study covered five criteria. Scene consistency assessed whether object
appearance, position, and scene layout remained consistent through turns, return paths, and revisits.
Action adherence assessed whether the generated motion followed the displayed controls, including
forward and backward movement, lateral movement, and turning. Temporal consistency assessed
flickering, abrupt changes, and continuity across action switches and chunk boundaries. Visual
quality assessed clarity, texture, structural integrity, and visible distortions or artifacts. Overall
preference captured which result participants preferred after considering these aspects together.
As shown in fig. 6, participants preferred predictor-augmented videos on all five criteria for all four
generators. This preference was stronger for scene consistency, action adherence, and temporal
consistency, while visual quality showed a more modest advantage. The pattern is consistent with
the predictor’s role in anticipating scene transitions. By estimating the next state from the current
generated latent and the next action, the predictor supplies a visual reference for how the scene
should evolve. Modulation uses this reference to refine each new chunk before it becomes part
of the history. The preference pattern thus supports future-state guidance for preserving coherent,
action-responsive scenes during sustained interaction.
