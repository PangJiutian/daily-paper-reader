## 摘要
交互式视频世界模型旨在遵循用户动作，同时在长时交互中保持场景一致性。基于历史的方法复用已生成的潜变量以保留场景内容，但这种复用的三个局限会导致误差循环传播。1）每次交互生成的潜变量都被保留为历史，可能包含模糊细节、几何畸变或语义漂移。2）尽管检索到的历史内容与当前场景匹配，它仍可能包含错误，并被带入下一个片段。3）新的输出随后又成为后续交互的历史，可能通过反复复用强化相同错误。为限制这一循环，我们旨在生成下一交互视频片段之前，根据当前生成的潜变量和下一动作预测未来场景状态。该未来状态先验为下一片段提供引导，旨在减少从历史中前向传递的错误。为此，我们提出一种具有跨模型适应性和预测引导调制能力的即插即用因果下一片段预测器（Causal Next-Chunk Predictor, C-NCP）。我们将 C-NCP 集成到四个基础生成器中，并在三个基准上评估增强模型，用于交互式长视频生成和动作条件世界建模。大量实验表明，在不同生成设置下，误差累积减少，长时程一致性得到提升。项目页面为 https://GuangYuanKK.github.io/futureworld。

## Abstract
Interactive video world models aim to follow user actions while maintaining scene consistency over extended interactions. History-based methods reuse generated latents to preserve scene content, but three limitations of this reuse contribute to error recirculation. 1) The latent generated at each interaction is retained as history, potentially containing blurred details, geometric distortions, or semantic drift. 2) Although retrieved historical content matches the current scene, it can still contain errors that are carried into the next chunk. 3) New outputs then become history for later interactions, potentially reinforcing the same errors through repeated reuse. To limit this cycle, we aim to predict the future scene state from the current generated latent and the next action before generating the next interaction's video chunk. This future-state prior provides guidance for the next chunk, with the aim of reducing the errors carried forward from history. To this end, we propose a plug-and-play Causal Next-Chunk Predictor (C-NCP) with cross-model adaptability and prediction-guided modulation. We integrate C-NCP into four base generators and evaluate the augmented models across three benchmarks for interactive long-video generation and action-conditioned world modeling. Extensive experiments demonstrate reduced error accumulation and improved long-horizon consistency across diverse generation settings. The project page is at https://GuangYuanKK.github.io/futureworld.

## 1. 核心问题与研究背景

- **研究对象**：交互式视频世界模型（Interactive Video World Models），在用户动作（移动、转向、相机控制等）驱动下自回归生成可持续演化的视觉环境。
- **核心矛盾**：长时交互要求每个新视频块既跟随动作、又保持场景结构与语义一致；但局部生成缺陷会随交互不断累积。
- **现有范式的问题**：基于历史的方法（检索并复用已生成的潜变量）虽能保留场景内容，却造成 **误差回流（error recirculation）**，具体表现为三点：
  1. 每次交互生成的潜变量被直接存入历史，可能含模糊细节、几何畸变、语义漂移；
  2. 检索到的历史视图即使与当前场景匹配，本身也可能带有错误，并被带入下一块；
  3. 新输出又成为后续历史，反复复用会强化同一错误。
- **研究动机**：不再仅从"可能有缺陷的历史"中选取内容，而是在生成下一交互视频块**之前**，由当前生成潜变量与下一动作**显式预测未来场景状态**，形成未来状态先验以抑制误差前向传播。
- **核心研究问题**：如何从当前生成潜变量与下一动作预测未来状态，并用其引导后续生成、限制跨交互误差传播？

## 2. 方法论

### 2.1 核心思想

- 提出 **Causal Next-Chunk Predictor（C-NCP）**：一个即插即用的因果下一片段预测器，从真实视频转场中学习"动作如何改变场景"，估计完整的下一潜变量块，作为未来状态先验。
- 预测与生成的形式化流程：
  - 预测：`ẑ_{t+1}^{(d)} = P_φ^{(d)}(ẑ_t^{(d)}, u_{t+1})`
  - 生成：`ẑ_{t+1}^{(d)} = G_θ^{(d)}(H_t, u_{t+1}; ẑ_{t+1}^{(d)})`
  - 其中 `t` 为交互块索引，`d` 为 VAE 域，`P_φ` 为可训练预测器，`G_θ` 为冻结生成器，分号表示预测引导调制。
- 生成完成后，**实际生成输出**（而非预测先验）更新历史并作为下一次预测输入，形成闭环。

### 2.2 理论形式化

- 用贝叶斯决策理论将预测建模为最小化条件期望损失：`a* = argmin_a E[ℓ(a,Y)|C]`，其中 `C=(x_t, u_{t+1})`。
- 在平方误差与有限二阶矩下，最优解为条件均值 `m(C)=E[Y|C]`。
- 通过正交投影分解：`E‖Y−f(C)‖² = E‖Y−m(C)‖²`（条件不确定性）+ `E‖m(C)−f(C)‖²`（可约预测风险），据此论证学习未来状态先验的合理性。
- 论文明确说明：该分析仅针对平方误差，**不保证**归一化混合损失的最优性，也不保证 rollout 误差收缩。

### 2.3 跨模型适应性（Cross-model Adaptability）

- 不同基础生成器使用不同 VAE 潜变量（通道数 16 / 48 / 128，分布与尺度不同）。
- **Input Adapter (d)**：1×1×1 通道映射，将各域潜变量映射到共享隐藏空间，保留各自时空网格。
- **Action/Camera Adapter + Condition Fusion**：编码动作控制并对齐到查询网格，主干输入为 `H(0) = [I_d(x_t); Q + ΠA_d(u_{t+1})] + E`，其中 `Q` 为学习起始 token 加前序切片，`E` 为类型/域嵌入。
- **Output Head (d)**：将共享主干特征映射回对应 VAE 的原生通道空间，输出完整潜变量（非输入残差）。

### 2.4 因果时空主干

- 结构：**Causal Temporal Attention → FFN → Dense Spatial Attention → FFN**，共 4 个 block，隐藏宽度 768，12 个注意力头，FFN 扩展比 4，无 dropout，采用预归一化与残差连接。
- 因果掩码：未来查询只能关注当前输入位置及**更早的未来切片**，屏蔽自身与后续目标，保证预测方向与自回归生成一致。
- 概率链式分解：`p*(Y|C)=∏_τ p*(Y_τ|Y_<τ, C)`，逐切片条件预测。

### 2.5 两阶段下一片段预测训练

- 预测器从零训练，早期预测不可靠，直接跨块反馈会破坏优化，因此：
  - **Stage I**：块间输入 = 预测块 + 真实块（逐元素相加，保留预测内容并给予 GT 支撑）；
  - **Stage II**：移除 GT 直接相加，改用纯预测块作为块间反馈，适配推理分布。
- 两个阶段均保留**块内 teacher forcing**，且均从真实初始块开始。
- 损失函数（每阶段）：
  - 归一化 L1 误差 + 归一化 L2 误差 + **相邻切片时序差分监督**（匹配"变化量"而非抑制运动）；
  - 权重 `λ1=1, λ2=1, λtemp=0.25`；用目标状态与目标差分的标准差 `s_n, r_n` 做归一化（下限 1e-3）；
  - 仅更新预测器与适配器，VAE 与基础生成器全程冻结。

### 2.6 推理期预测引导调制

- 不使用直接拼接（会改变主潜变量形状、需生成器重新学习使用额外输入），而采用**形状保持的通道级残差调制**（受 FiLM / AdaIN 启发）：
  - 相对尺度：`γ_c = σ_c(ẑ_{t+1}) / σ_c(ẑ_t) − 1`
  - 均值偏移：`β_c = μ_c(ẑ_{t+1}) − μ_c(ẑ_t)`
  - 原位更新：`ẑ_{t+1,c} ← ẑ_{t+1,c} + α(γ_c·(ẑ_{t+1,c}−μ_c)/σ_c + β_c)`
- `α ≥ 0` 控制调制强度；系数按通道广播到时空维度；推理时两个网络均冻结。

## 6. 主要结论与发现

- **一致提升**：四个基础生成器在三个基准上**所有指标**均获提升，说明收益不局限于单一模型。
  - RealEstate10K-test：Matrix-Game 3.0 + Ours 平均分最高（0.8314，基线 0.8124）；

- **误差累积受抑制**：Subject/Background

Consistency 的提升在长时交互中尤为突出，说明预测先验确实缓解了“错误潜变量反复回流—被强化”的链条；这与论文对 error recirculation 的机制分析一致，即收益主要来自**阻断缺陷进入历史**，而非单纯提升单块生成质量。

- **消融验证了各设计要素的必要性**（Matrix-Game 3.0 基座）：
  - **因果性**：改为双向预测器后性能下降，说明预测必须与自回归生成方向一致，否则会引入“未来信息泄漏”式的错配；
  - **动作条件**：去除动作输入后提升明显衰减，表明预测器学到的核心是“动作—场景变化”的映射，而非无条件外推；
  - **时序差分损失**：去除后运动相关指标变差，说明该项在匹配“变化量”而非压制运动方面起作用；
  - **融合方式**：直接拼接不如形状保持的通道级残差调制，印证了“不改变主潜变量形状、冻结生成器即可即插即用”的设计初衷；
  - **两阶段训练**：One-stage（纯 Pred 或纯 GT 反馈）均不及 Two-stage GT→Pred，说明早期用 GT 支撑稳定优化、后期切换到纯预测以对齐推理分布是必要的。
