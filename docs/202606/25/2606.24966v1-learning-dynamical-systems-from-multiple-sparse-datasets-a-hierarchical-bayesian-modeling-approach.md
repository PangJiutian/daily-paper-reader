## 摘要
从稀疏、含噪声且不规则采样的数据中估计动力系统参数通常是严重病态的。当多个相关数据集可用时，如果对共享结构和变异性进行适当建模，它们能提供额外信息。我们提出了一种用于动力系统中概率元学习的层次贝叶斯框架，将数据集特定参数建模为从共享总体分布中抽取的样本。在基于梯度的MCMC中嵌入数值ODE求解器，以实现对共享总体和数据集特定参数分布的高效后验推断。实验表明，与未合并方法相比，预测性能有所提升，突显了在稀疏数据环境下进行数据高效系统辨识的潜力。

## Abstract
Estimating parameters of dynamical systems from sparse, noisy, and irregularly sampled data is often severely ill-conditioned. When multiple related datasets are available, they provide additional information if the shared structure and variability are properly modeled. We propose a hierarchical Bayesian framework for probabilistic meta-learning in dynamical systems, modeling dataset-specific parameters as draws from a shared population distribution. A numerical ODE solver is embedded within gradient-based MCMC to enable efficient posterior inference of the shared population and dataset-specific parameter distribution. Experiments show improved predictive performance over unpooled methods, highlighting the potential for data-efficient system identification in settings with sparse data.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：从稀疏、含噪声且不规则采样的数据中估计常微分方程（ODE）动力系统的参数时，逆问题往往是病态的，表现为实践上的不可辨识性（非结构性的非可辨识性）。单个数据集信息量不足，导致参数估计不可靠。
- **研究动机**：当存在多个相关但非完全相同的系统数据集时（例如同一生态系统的不同区域或同一药物的不同患者），可以通过跨数据集学习共享结构来改善每个数据集的估计。然而，现有方法要么假设系统完全相同（将数据合并为一个大数据集），要么完全独立处理（丢弃共享结构）。两种极端都不合适。
- **背景**：传统系统辨识使用正则化或单数据集贝叶斯推断，但无法利用多个数据集间的相似性。混合效应模型（多层次模型）在统计学中有悠久传统，但大都要求参数到观测的映射为线性或闭合形式，不适用于非线性ODE。现有的层次贝叶斯ODE方法仅适用于有解析解的特殊情况（如线性ODE），或者使用基函数代理。元学习方法虽能挖掘共享结构，但需要大量数据集（通常由数字孪生生成），不适合中等数量实测数据的场景。
- **本文目标**：针对中等数量弱信息数据集，提出一种层次贝叶斯建模（HBM）框架用于ODE系统的概率元学习，允许数据集特定参数服从共享的总体分布，利用梯度MCMC结合可微ODE求解器进行高效后验推断。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：层次贝叶斯建模（Hierarchical Bayesian Modeling, HBM）。将每个数据集的参数θ_j视为从共享的总体分布p(θ|ϕ)中抽取的样本，其中ϕ是总体超参数；超参数本身又有先验p(ϕ)。通过对所有数据集同时进行后验推断，整体数据集可以互相“借用力量”，改善弱信息数据集的估计。
- **形式化描述**：
  - 超参数ϕ ∼ p(ϕ)
  - 每个数据集特定参数θ_j ∼ p(θ_j | ϕ)（对所有j相同）
  - 观测y_ji ∼ p(y_ji | t_ji, θ_j)，其中观测分布通过ODE解和测量噪声导出：
    - 状态：由ODE数值积分得到ẋ_ji = x0 + ∫₀^{t_ji} f(x(s), s, θ_f) ds
    - 输出：ŷ_ji = g(ẋ_ji, θ_g)
    - 似然：p(y_ji | t_ji, θ_j) = p_η(y_ji - ŷ_ji; θ_η)（加性噪声假设下）
- **关键技术细节**：
  - **可微ODE求解器**：将ODE数值积分嵌入计算图（使用JAX + Diffrax），使得似然关于θ_j可微，从而能够使用基于梯度的MCMC（如NUTS）。
  - **梯度MCMC**：使用No-U-Turn Sampler（NUTS），因其在高维后验空间（参数数量随数据集数增长）中高效。
  - **实现**：基于NumPyro（Pyro的JAX版）和Diffrax，采用5阶Runge-Kutta求解器配合PID步长控制。
  - **代码开源**：提供了可复现的实现链接。
- **算法流程**：
  1. 定义层次先验：包括超参数的分布（如半正态分布）和数据集特定参数的分布（如以超参数为中心的正态分布）。
  2. 对于每个数据集j，计算ODE数值解，得出预测观测值。
  3. 基于观测数据和预测值计算似然。
  4. 使用NUTS从联合后验p(ϕ, θ_{1:J} | D)采样，得到M＝10,000个后验样本。
  5. 对于新数据集，后验预测分布p(θ_{J+1}|D)可通过从超参数后验中抽取ϕ，再从中抽取θ_{J+1}获得，作为学习到的先验。
