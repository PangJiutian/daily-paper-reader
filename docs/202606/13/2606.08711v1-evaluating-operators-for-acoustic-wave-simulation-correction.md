## 摘要
校正有限差分求解器产生的数值色散伪影是计算波物理学中一个公认的挑战，但现有方法仅评估了有限的基于CNN的架构，且仅应用于弹性波动方程。我们将深度有限差分框架实例化到二维各向异性声波传播中，将四阶有限差分代理与伪谱参考配对，涉及27,000个非均匀速度场。我们在统一的10折交叉验证协议下对从线性回归到傅里叶神经算子的十二种校正架构进行了基准测试。

## Abstract
Correcting numerical dispersion artifacts from Finite Difference solvers is a well-identified challenge in computational wave physics, but existing approaches evaluate only a restricted family of CNN-based architectures and have been applied exclusively to the elastic wave equation. We instantiate the Deep Finite Difference framework on two-dimensional anisotropic acoustic wave propagation, pairing a fourth-order Finite Difference proxy with a Pseudo-Spectral reference over 27,000 heterogeneous velocity fields. We benchmark twelve correction architectures, from linear regression to Fourier Neural Operators, under a unified 10-fold cross-validation protocol.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：有限差分（FD）求解器在模拟声波传播时会产生数值色散伪影（离散化误差），导致模拟结果偏离真实解。现有机器学习校正式方法仅评估了有限几种CNN架构，且只应用于弹性波动方程，从未被用于声波方程，也缺乏对不同架构的系统性基准比较。
- **研究动机**：填补这一空白，为声波模拟校正任务提供首个全面的算子选择基准，探索哪种学习方法最适合校正FD求解器产生的色散误差。
- **背景**：基于“求解器在回路”（solver-in-the-loop）框架，用两个不同精度的数值求解器生成成对的次优解和参考解，训练神经网络学习映射。前人工作（如Gadylshin等用U-Net，Siahkoohi等用CNN，Rincon等用FNO）均限于弹性波且只评估单一架构。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：采用Deep Finite Difference（Deep FDM）框架，将校正任务建模为算子学习——从低阶FD求解器的输出函数空间映射到高阶伪谱（PS）求解器的输出函数空间。
- **关键技术细节**：
  - 使用二维各向异性声波方程：\(\frac{\partial^2 p}{\partial t^2} = c^2 \nabla^2 p + s\)。
  - 代理求解器：四阶中心差分FD（空间截断误差\(O(\delta x^4)\)，时间二阶leapfrog）。
  - 参考求解器：傅里叶伪谱（PS）离散化（空间精确至机器精度，时间二阶leapfrog）。
  - 网格：二维周期性均匀网格，\(N_t=256\)时间步，记录顶部表面压力演化，得到trace对\((y_{FD}, y_{PS})\)。
  - 异质速度场从Negahdari等(2025)提取，外部激励为Ricker子波调制二维高斯空间包络。
  - 生成27,000个trace对，初始RNMSE为0.3856。
- **校正架构**：共12种，分为两类：
  - 基线方法（直接基于\(y_{FD}\)）：线性回归（LR）、K近邻（KNN）、极随机树（ET）、主成分回归（PCR）。
  - 神经网络方法（输入为\(y_{FD}\)与PCR初始校正\(\hat{y}_{PCR}\)的组合）：MLP、1D-CNN、2D-CNN、UNet、傅里叶神经算子（FNO）。
  - 所有神经网络输出与线性组合权重\(\alpha, \beta, \gamma\)共同优化：\(\hat{y} = \alpha y_{FD} + \beta \hat{y}_{PCR} + \gamma y_{NN}\)。
- **评估指标**：均方根归一化误差（RNMSE）。

## 3. 实验设计：使用的数据集、benchmark、对比方法

- **数据集**：基于二维各向异性声波方程，在27,000个异质速度场上生成trace对（每个速度场一个场景），速度场来源于已有公开数据（Negahdari et al., 2025）。

## 6. 论文的主要结论与发现

- **所有ML管道均能降低色散误差**：所有使用PCR初始猜测的校正方法均优于基线PCR，证明FD与PS之间存在可被非线性模型捕获的关系。
- **PCR初始猜测至关重要**：移除PCR初始猜测直接校正\(y_{FD}\)的管道性能显著更差，表明先消除线性色散分量有助于非线性校正。
- **2D卷积优于1D卷积**：CNN2d（RNMSE=0.080424）优于CNN1d（0.084437），说明色散误差具有空间依赖性。
- **FNO达到最佳校正性能**：FNO（RNMSE=0.079006）在均值上优于所有其他架构，但统计上与CNN2d无显著差异（临界差异图显示二者在同一clique内）。绝对提升幅度较小（RNMSE从0.0804降至0.0790），且FNO方差更大、参数更多。
- **理论预期未完全验证**：虽然假设FNO的全局傅里叶卷积与色散误差的频谱特性更匹配，但实验结果未提供显著统计证据支持。

## 7. 优点

- **首次系统基准**：填补了声波模拟校正领域缺乏架构对比的空白，涵盖了从经典ML到深度学习的12种方法。
- **统一实验协议**：所有方法在相同数据、相同10折交叉验证、相同评价指标下比较，并进行了统计检验，保证了公平性。
- **改进的输入设计**：将PCR初始校正作为辅助输入，与FD trace一起馈入神经网络，有效提升性能，体现了“先线性再非线性”的设计思路。
- **开源数据和代码**：承诺公开实验代码和架构细节，促进可重复性。

## 8. 不足与局限

- **统计显著性不足**：因折数较少（n=10），Wilcoxon检验难以区分FNO与CNN2d等方法的显著差异，结论需更大规模实验验证。
- **数据集单一**：仅使用二维各向同性/异性声波，未扩展到三维、弹性波、粘弹性或含吸收边界等复杂情况。
- **未考虑物理现实差距**：仅校正数值求解器之间的偏差，未处理波方程本身忽略的物理现象（如衰减、介质形变）。
- **计算开销分析缺失**：未报告各模型训练时间、推理速度或参数数量，无法为实际部署提供权衡依据。
- **超参数未系统调优**：各架构的超参数（如层数、卷积核大小、FNO模式数等）固定或仅简单设置，可能未达到各自最优性能。
- **FNO的方差问题**：FNO虽然均值最好，但方差更大，稳定性不如CNN2d，需更多重复实验确认。
